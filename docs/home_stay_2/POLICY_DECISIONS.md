# 사용자 확정 정책

## 검색 가격 필터 — 2026-10-10

- 확정한 기준: 선택한 입·퇴실 기간의 총액 (`selected_stay_total`).
- 범위: 검색 화면과 후속 검색·견적 엔진의 가격 범위 비교.
- 숙박 1박 요금과 비숙박 주·월 요금을 그대로 같은 가격 범위에 비교하지 않는다.
- 날짜가 없으면 가격 범위를 적용하지 않으며, 유효한 기간 견적 부재를 0원이나
  임의 30일/일할 환산으로 메우지 않는다.
- 부분 주·월, 세금, 관리비, 추가비, 보증금, 수납·환불·정산은 이번 결정으로
  승인되지 않았다. 원문의 나머지 미확정 정책과 운영 승인 Gate는 유지한다.

## 권장안 자동 선택 위임 — 2026-10-11

사용자가 일반적인 개발·사업정책 선택을 권장안으로 자동 진행하도록 위임했다.
선택 근거·영향·검증을 기록하고 사용자 Phase 18까지 연속 진행한다.
운영 DB migration·실제 PG/정산·운영 배포의 개별 승인 Gate는 유지한다.

## 매물 공개 시점 — 권장안 자동 선택, 2026-10-11

- P06-PUBLICATION-TIMING: 관리자 등록권한·공개정보 확인 후 공개.
- 초안 → 제출 → 관리자 확인 → 승인/반려. 수정은 기존 승인을 재사용하지 않고
  새 버전으로 재검토한다. 철회는 원본·감사기록을 삭제하지 않는다.
- 자동 기본 범위는 제한공개; 연락처·정확한 건물명/주소/사진/좌표는 공개하지 않는다.
- 건축물 용도에 따른 적법성 판정/등록 차단은 추가하지 않는다.
- 유형은 운영자 명시 선택을 관리자에게 표시하며 공적 인허가 판정과 혼동하지 않는다.
- 이 정책은 개별 실제 매물/권한/운영 연결을 승인한 것이 아니다.

등록 개발의 권장 기본값: 공개 승인은 365일 후 재확인하며, 편집 즉시 공개를 해제하고
새 revision 검토를 요구한다. 제출에는 비공개 사진 1장 이상·명시적인 운영자 책임 동의가
필요하다. 건물전체와 개별 공간의 중복 공개는 보수적으로 차단한다. 공적 분류와
운영자 선언을 구분하며 관리자 확인을 정부 인증·적법성 판정으로 표시하지 않는다.
**근거:** 권장안 자동 진행 위임에 따라 무기한 승인·과거 승인 재사용·중복 재고 노출을
피한다. 실제 영업 적법성·운영 배포·실제 돈 이동 승인과는 별개다.

## 가격/Calendar 권장 개발 정책 — 2026-10-11

자동 위임으로 Asia/Seoul·KRW·[입실,퇴실), 주=7일, 월=입실 기념일 기준
달력 월(없는 날짜는 말일)을 선택한다. 전체 주·월 조합만 허용하고 유효 조합 중
최소 총액을 선택한다. 부분 주/월을 임의 일할 계산하지 않고 견적 불가로 표시한다.
운영자가 입력하는 표시 숙박료는 필수 비용을 포함하는 금액이며 숨은 추가비를
자동 합산하지 않는다. 보증금·실제 세금·수납/정산은 별도 명시 항목과 승인 경계다.
요금 0/누락은 유효 견적이 아니며 무료 예약으로 해석하지 않는다.
**근거:** 원문 1박/7일·날짜별/주월 요금을 보존하면서 임의 30일 환산, 숨은 비용,
정확한 기간 견적 없는 최저가 표시를 피한다. 확정 가격은 원래 snapshot 계약에
명시적인 기간·버전·조정항목으로 고정하고 이후 요금 변경과 분리한다.
