# HOME & STAY 2.0 — 18단계 계획

상세 실행 기준은 `stages.json`, 고정 요구사항은 `MASTER_SPEC.md`가 기준이다.
각 단계는 두 개의 필수 acceptance ID(총 36개)를 가진다.
현재 모두 **미구현(null)**이며 실제 기능 검사가 연결되기 전에는 단계 완료 불가.
어떤 개발 기능도 0.5단계에서 이미 완성됐다고 처리하지 않는다.

## 모든 단계 공통 gate

보존 기준 + 전체 공통 회귀 + 하네스 검사 + 이전 완료 단계 acceptance +
현재 단계 acceptance가 모두 PASS여야 완료 가능. 0개 검사/skip/expected failure/
timeout/소스 변경/미검토 테스트는 통과가 아니다.

기존 분류·활성 신고, 공매 판정, Relay fail-closed·batch token·admin guard,
공매 지도 동작, 관리자 수집 범위, 제한공개 UI를 검사한다.
동결된 schema/수집·분류·쿼터/중계 파일은 해시, 기존 616 route 조합은
파일·함수·메서드·경로 보존으로 검증. 전체 기존 런타임 기능에 대한 완전한
회귀 실증은 아니며 별도 격리 통합환경 검증이 필요하다.

## 승인 gate

17단계 PG/정산은 모의 검사만 수행. 18단계는 릴리스 준비이지 배포 단계가 아니다.
운영 migration, 실제 PG/정산, 운영 배포는 각각 별도 owner approval.
`request-approval`은 요청 기록만 남기며 승인/실행하지 않는다.
