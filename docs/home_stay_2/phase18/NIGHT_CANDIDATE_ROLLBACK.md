- 시작 시 이미 변경된 파일은 이전 승인 개발 작업이다. 덮어쓰거나 HEAD로 일괄 복원하지 않는다.
- 시작 작업 트리 지문과 diff는 `generated-artifacts/night-candidate-baseline/`에 보관한다.
- 기존 가격 엔진·DB 스키마·migration 파일을 변경하지 않는다.
- 운영 migration, main 병합, 실제 결제/정산, 실제 발송, 운영 게시는 금지한다.
- 소유 임시 DB Preview는 재시작 시 초기화된다. 예약·채팅 테스트 데이터는 운영 복구 대상이 아니다.

## 게시 전 중단 기준

권한·개인정보·중복 예약·결제 금액·가격 동결·회귀검사에 필수 실패가 있거나,
실제 계정/토스/운영 데이터 연결이 미검증이면 배포 가능으로 선언하지 않는다.
개발 시설 스냅샷을 현재 운영 전체 시설수로 표시하지 않는다.
기능 통과를 목업 디자인 승인으로 대체하지 않는다.

## 롤백 순서

1. 실제 게시 전: 운영은 그대로 두고 후보 변경을 이전 체크포인트와 대조한다.
   초기 작업 트리의 다른 변경을 보존한다. 일괄 reset이나 원본 이미지 덮어쓰기는 하지 않는다.
2. 게시 이후의 복귀 계획: 승인된 이전 운영 소스·빌드·설정 지문을 확보하고
   새 유입/예약/결제를 안전하게 중단한 뒤 승인된 이전 릴리스로 복귀한다.
3. 코드 복귀를 운영 DB 원장 복구로 오인하지 않는다. 예약·결제 등 새 쓰기가 발생하면
   독립적인 데이터 대사와 복구 승인이 필요하다. 운영 DB에 down migration을 자동 실행하지 않는다.
4. 복귀 후 로그인·지도·예약 조회·채팅 조회·결제 상태를 재검증하고 결과를 기록한다.

실제 운영 변경창, 승인된 후보 commit, 실제 PG 키 쌍과 계정 연결 증거가 없으면
게시/전환/복귀 실행 자체를 시작하지 않는다.
