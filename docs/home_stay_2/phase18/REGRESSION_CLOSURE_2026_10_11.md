## 변경과 확인 범위

1. 관리자 검사는 제거된 카드 이름 대신 현재 통합 동기화 보드의
   상태·한도·오류·갱신·재실행·중복 실행 방지를 확인한다.
   기존 보드·실행 제어 브라우저 검사도 전체 실행에 포함됐다.
2. 모바일 상세에서 의도적으로 숨기는 검색 토글을 누르지 않는다.
   관심단지·지도위치·주변 포인트·강조 해제·재진입·최근조회는 유지해 검사한다.
3. 자동 상세 위치 이동이 클릭으로 해제한 강조를 다시 켜던 문제를 수정했다.
   SDK의 동기 콜백도 뒤쪽 상태 선언이 완료된 후 초기화하도록 수정했으며
   동기·비동기 콜백 단위 검사를 추가했다.
4. 익명 현황조사는 공개 공고와 13개 가림 항목, 서버측 정보 제한,
   멤버십 이동을 실제 격리 HTTP로 확인한다.
   활성 멤버십 신청 흐름은 별도 멤버십 브라우저 검사로 유지한다.
   관리자 실제 로그인·설정 입력·이력·약관 검사도 유지한다.
5. 터치 검사는 해제 이벤트의 실제 값을 기준으로 이후 반복이 멈추는지
   확인한다. 해제 명령 전후의 통신 지연 중 증가를 오류로 오판하지 않는다.
   Safari 엔진 검사는 물리 iPhone 검증이 아니다.
6. WebKit에 필요한 공개 EGL 설정 경로만 검사 실행기에 보존한다.
   운영 DB·메일·문자·외부 제공기관 권한 차단을 해제하지 않았다.
7. 공매 행·지역 선택지에 악성 HTML/속성/스크립트 문자열을 넣는
   PC·모바일 검사를 추가했다. 원문은 문자로 표시되고 삽입 DOM·스크립트
   실행은 없음을 확인했다. 이는 관련 HTML 삽입 경고의 검토 근거이지
   보안 스캔을 새로 실행했다는 주장은 아니다.

## 개발 실행과 백업

개발 기본 Project 묶음에서 Backfill Retry·Fill PK·Fast Sync 연결만 제거했다.
각 독립 워크플로 정의와 기존 운영 실행은 중단·재시작·삭제하지 않았다.
`.replit`은 전체 원문을 보존하며 검증 후 교체했고 해당 연결 외 차이는 없다.

Start application만 재시작했고 소유 가상 DB Preview의 PC·모바일 표시를
확인했다. 캡처는 `generated-artifacts/final-preview/`에 분리 저장했다.
Preview는 운영 로그인이나 실제 토스가 아니라는 안내를 유지한다.

위 기능 소스는 GitHub `development/home-stay-2-phase-1-design`에 백업했다.
blob·tree·commit 해시와 부모·메시지 줄바꿈을 대조하고 force:false로 갱신했다.
main `a424b3b1f13efbee73b96a093a43c20a412c1358`은 변경하지 않았다.
이 기록을 저장하는 후속 커밋은 문서 변경만 포함하며 기능 소스와 구분한다.
