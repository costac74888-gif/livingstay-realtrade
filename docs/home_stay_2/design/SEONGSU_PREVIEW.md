# 성수동 가상 매물 직접 체험

2026-10-11 사용자 추가 요구. 기존 참고 목업의 파랑·금색 디자인과 2.0 구조를
유지하면서 실제 매물 없이 직접 비교·예약을 진행하는 개발 Preview를 추가했다.
이 문서는 이전 `MOCKUP_IMPLEMENTATION.md`의 사진·JS 변경 제한 이후 추가 범위다.
기존 19/19 검사 결과는 이전 복원 작업의 결과이지 이 변경 전체의 재검사 결과가 아니다.

## 구성과 격리

- 성수동1가·2가 숙박 7개 / 비숙박 주·월 단기임대 7개, 총 14개.
- 매매·영업권 양도·공매 각 3개, 별도 레이어와 상세 요약. 실제 계약·사건·신고 없음.
- 총 23개 가상 지도 좌표. 실제 주소나 소유자의 위치가 아니다.
- 4종 AI 가상 공간 이미지, 매물별 가격·면적·인원·설명·옵션과 이용 가능 기간.
- Asia/Seoul 기준 내일부터 540일 범위의 테스트 가격 원장.
  일부 매물은 첫 가능일부터 8일 뒤 3일 마감. 예약 점유 기간도 상세 달력에 반영.
- 숙박 최소 1박·일별 요금(주말 테스트 할증), 비숙박 최소 7일·주/달력 월 요금.
  최초 화면의 기본 7일 기간은 두 종류 14개를 함께 보여준다.
- 소유한 임시 PostgreSQL의 `hs2_dev` 원장만 사용하며 서버 재시작 시 초기화.
  개발/운영 DATABASE_URL과 제공자·발송 키를 전달하지 않는 기존 bootstrap 유지.
- 일반 HTML에는 데모 활성 플래그를 넣지 않는다. 격리 서버에서만 플래그·
  `preview_demo` 데이터를 붙인다. 일반 공유 화면의 비공개 사진·보호 필터는 유지.
  실제 비공개 사진 저장 URL이나 실제 메타데이터를 공개 계약에 승격하지 않는다.

## 체험 경로와 계정

- PC: `/hs2/consumer`
- 모바일 목록↔지도: `/hs2/search/mobile/`
- PC 지도/다른 레이어: `/hs2/search/`
- 체험 안내: `/__development__/seongsu/`
- 선택 매물 상세: `/hs2/details/?public_id=…` (카드/지도에서 진입)
- 내 예약·운영자 승인: `/hs2/bookings/`
- 승인 후 결제 조건/모의 결제: `/hs2/finance/?booking_id=…`
- 운영자: `/hs2/dashboard/` 및 `/hs2/calendar/`
- 상태 확인: `/__development__/status`

가상 계정 101이 소비자·운영자로 자동 연결된다. 별도 비밀번호는 제공/입력하지 않는다.
실제 이메일 로그인·본인확인 검증을 대체하는 것이 아니며 체험자 간 데이터를 공유한다.
실제 연락처·소유자 정보·인증문서를 입력하지 않는다.

안내 페이지에 비교 → 필터 → 상세 날짜/가격 → 견적 확인 → 예약 신청 →
운영자 승인 → 금융 조건 동의 → 모의 결제 → 내 예약/대시보드 확인 순서를 제공한다.
마감일·최소기간·인원 초과·미동의 결제도 확인할 수 있다.

## 결제 구분과 미완료

**OwnedSandbox 모의 결제**만 연결했다. 실제 토스 테스트 API/SDK 연결 성공이 아니다.
가상 서버가 계약의 payable 금액을 읽고 owned provider 이벤트에 서명한다.
사용자 금액 입력이나 브라우저의 임의 paid 값은 받지 않는다. 동의와 CSRF를 확인하고
실제 원장/예약 상태를 갱신한다. 이미 captured인 계약의 재요청은 재결제하지 않는다.
일반 환경에는 이 endpoint가 등록되지 않으며 실제 토스 제공자로 교체해 실행할 수 없다.

실제 토스 테스트 연결, 실제 로그인/본인확인, 실제 지도 타일/GPS,
실제 매매 계약·영업권 양도·공매 입찰, 실결제·정산·지급·메일/SMS는 이 체험 범위가 아니다.
정확한 최종 승인 목업·글꼴/로고·실제 공개 사진의 일치도 여전히 미확정이다.

23개 마커와 native 상세, 지역/인원/면적/옵션 필터, 마감일 차단, 정확 주·달력 월,
비숙박 1박 거부, PC/모바일 사진·overflow·목록↔지도, 실제 저장된 예약/승인/금융 조건,
동의·CSRF 거부, UI 모의 결제와 멱등 재요청, 내 예약/대시보드,
일반 공유 템플릿의 비공개 유지와 JS 오류를 확인한다.

이 검사는 실제 토스·생산 DB·물리 휴대폰·최종 목업의 픽셀 일치를 증명하지 않는다.
