# 개발 Preview: 기준요금·기간 선택·등록 요금 미리보기

## 범위와 시작 기준

- 운영·배포·Secrets·DB 스키마·마이그레이션·SCHEMA_VERSION 변경 없음.
- 가격 엔진 변경 없음. 입실일 기념일 월 계산과 월·주 조합 최저가 유지.
- 시작 커밋: `f3c1cd82589f7807357a03c9a119075b8306dd07`.
- 시작 시 미저장 파일 23개는 `generated-artifacts/rate-ui/before-work.tar.gz`,
  추적 파일 차이는 `before-work.patch`, 보호 파일 SHA256은 `baseline.json`에 보관.
  커밋 해시만으로 시작 당시의 미저장 작업까지 복원할 수 있는 것은 아니다.
- 기존 Kakao 지도·우측 도구·사진/리스트 구조·검정 글자·원본 로고·올리브
  `#596044` 유지. 유형/기간 도우미는 기존 검색 영역에 추가한다.

## 공개 필드와 권한

- `base_rates`: 숙박형 `{night}`; 주·월형 `{week, month}`.
  미설정 단위는 null, 실제 0원은 0. 기준은 달력의 기본값이며,
  bool·문자열·소수·범위 초과·유형 혼용이면 전체 null.
- `base_rate_notice`: 기본 요금이며 날짜에 따라 다를 수 있습니다.
- `quote`: 기존 공개 견적 그대로. 기준요금에서 총액을 곱하거나 새로 만들지 않는다.
- `quote_issue`: 실제 `EXACT_PERIOD_QUOTE_UNAVAILABLE`에만 기간 안내.
- `candidate_check_outs`: 기존 엔진으로 검증한 퇴실일만. 클릭 시 재검색하며,
  결과가 사라지면 공개 견적 재확인으로 실제 실패 이유를 확인한다.
- `period_hidden_count`: 전체 유형에서 7일 미만일 때만 제공.
  동일한 공개·요약·지역·속성·경계·가격 조건을 적용한 뒤 페이지 나누기 전에 계산.
  숨긴 가격, 권한 없음, 재고 없음, 차단일, 가격 필터에 맞지 않는 항목은 세지 않는다.
- 승인·검토 차수·게시 상태·기간 만료·등록 권한·활성 회원·사업장 맥락·현재
  달력 버전·필수요금 동의 확인을 유지하며 조회 중 철회도 재확인한다.
- 검색의 가상 표시 데이터도 허용 목록을 적용한다. 일별/기간별 요금,
  차단일 목록, 내부 신청 ID, 등록한 비공개 사진은 검색에 실어 보내지 않는다.
  동의하지 않은 방/면적/인원/편의시설은 가상 메타데이터로 우회 공개하지 않는다.

## 화면 동작

- 큰 가격: `1박`, `1주`, `1개월` 기준요금. 작은 가격: 실제 선택기간 총액.
  주·월형은 실제 일수로 표시하며 10일을 2주 등으로 바꾸지 않는다.
- 지도도 숙박형 `/박`, 주 우선 `/주`, 주 미설정 시 `/월`.
  정확한 원 금액과 단위는 버블·도움말·선택 카드에 유지한다.
- 숙박형 1/2/7박, 주·월형 1/2/4주 및 1/3개월.
  월말·윤년은 입실일 기념일로 보정하고 30일 월을 만들지 않는다.
- 주·월형으로 전환하면 7일을 기본 선택한다. URL·새로고침·뒤로가기와
  선택한 날짜/유형을 동기화한다.
- 등록폼은 해당 유형의 가격만 표시·활성화한다. 숨긴 값은 지우고 전송 키도
  생략한다. 다른 유형으로 돌아와도 이전 값을 되살리지 않는다.
- 소비자와 같은 요금 표기와 명시적인 가상 사진·가상 위치를 미리 보여준다.
  0원과 유효한 주 요금 대비 월 2배 미만/5배 초과는 경고만 한다.
  기존 필수 항목·최소 7일·정수/범위 검증은 유지한다.

## 검증과 증거

- 등록된 전체 회귀 61그룹 PASS. unittest 448개, Node 정식 테스트 4개,
  별도 시나리오 스크립트 18그룹 포함. 이 숫자를 개별 단정 수로 합산하지 않는다.
- 신규 공개/기간 단위 검사 7개, 실제 격리 SQL 검사 7개, Node 표시 검사 4개는
  위 전체 회귀에 포함된다.
- 실제 HTTPS Preview의 1440/390 브라우저 검사와 별도 브랜드/레이아웃 검사.
  실행 결과는 `generated-artifacts/rate-ui/browser-checks.json`,
  `full-regression.json`, 각 스크린샷과 기존 브랜드 검사 결과에 보관한다.
- 실제 요금/기간/등록 브라우저 시나리오 9개, 원본 로고·색·화면 경로 검사 24개,
  기존 성수 체험 E2E 11개 모두 PASS. 후자는 차단일·견적·예약·운영자 승인·
  명시 동의한 signed mock 결제·재전송 멱등성을 포함하며 실제 돈을 실행하지 않는다.
- 전체 회귀는 운영 DSN·외부 발송·결제 공급자 없이 임시 PostgreSQL/브라우저에서
  실행했다. 테스트 스키마 초기화와 실제 운영 스키마 변경을 혼동하지 않는다.
- 주요 실행: `HS2_CHROMIUM="$(command -v chromium)" node scripts/verify_hs2_preview_rates.cjs`.

## 한계

- 기존 가격 엔진은 양수 견적만 허용한다. 실제 기준 0원은 표시하지만 0원
  견적이나 예약 가능 상태는 만들지 않는다. 이것을 바꾸려면 별도 엔진 변경 승인이 필요하다.
- 재고/달력은 재검색 때 바뀔 수 있다. 추천일은 예약 보장이 아니다.
- Preview는 공유 가상 계정과 임시 DB를 사용하며 재시작하면 초기화된다.
- 일반 HTTP 캡처에서는 Kakao의 HTTP CDN을 기존 CSP가 차단할 수 있다.
  최종 실제 지도 증거는 HTTPS Preview 브라우저 캡처이며 CSP를 완화하지 않았다.
- 로컬 개발 브랜치에만 저장한다. 운영 게시·실제 토스 검증·원격 Push를 했다고
  표시하지 않는다. 최종 커밋 ID와 원격 미전송 상태는 사용자 완료 보고에서 제공한다.
