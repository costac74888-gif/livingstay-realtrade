# 개발 프리뷰 디자인 반영 — 화면 기본검사 완료 / 전체 기능 완료 아님

사용자 요청에 따라 246개 시안 항목을 현재 개발 프리뷰의 실제 경로에 대응한다.
246은 독립 페이지 수가 아니다: page 119, tab 70, popup 46, state 11이다.
기존 기능 페이지는 기존 HTML/JS/API를 유지하고 디자인 셸만 교체한다.
추가 화면은 실제 개발 프리뷰 경로로 제공하되 원장·실제 계정이 연결되지 않은
동작은 디자인 연결로만 기록한다. 단순 파일 보존을 기능 통합 완료로 표시하지 않는다.

관리자 접근은 기존 서버 관리자 세션을 사용한다. 공개 역할 선택으로 권한을
만들지 않는다. 운영 DB·실제 PG·발송·배포·Phase18 Gate는 변경하지 않는다.
전체 시설은 기존 검증된 공개 스냅샷이며 운영 라이브 연결로 표시하지 않는다.

최종 대응표는 독립 페이지, 탭, 팝업, 상태, 별칭을 구분하고 각 항목에
시안만 있음/프리뷰 반영됨/화면 검수 통과 및 기능 연결 범위를 별도로 기록한다.

## 확인 결과

- 246개 대응 항목 모두 실행 서버의 일반 `/hs2/` 경로에 반영했다.
- 페이지 정의 119개 중 별칭 20개 및 공통 컨트롤러 변형을 제외한
  독립 페이지 경로군은 86개다. 탭 70개, 팝업 46개, 상태 11개를
  독립 페이지로 추가 계산하지 않는다.
- 1440px / 390px 실제 캡처 492건. 가로 넘침·16px 미만 직접 텍스트·
  승인 가격 이외 색상·누락 이미지의 기본 자동검사 통과 492건,
  실행 오류 0건, 확인한 내부 링크 오류 0건.
- 관리자 캡처는 기존 설정된 비밀번호로 정상 로그인한 실제 개발 서버 세션이다.
  임시 인증 우회·운영 관리자 로그인·실제 토스 검증은 하지 않았다.
- HTTPS 개발 프리뷰에서 카카오 지도 ready 및 가상 숙소 14개 표시,
  카드 선택 후 상세 패널 표시를 별도로 확인했다.
- 기존 API/가상 원장 연결 항목 45개, 디자인·로컬 UI만 연결된 항목 201개.
  숫자는 별칭을 포함하며 45개의 서로 다른 백엔드 기능이라는 뜻이 아니다.
- 기존 예약·요금·원장·DB 기능 모듈은 변경하지 않았다.
  경로/인증/공개 시설 검사 16건과 운영 경계 선택 검사 2건이 통과했다.
  전체 운영 경계 검사 묶음은 실행 제한 시간으로 완료하지 못했다.
- 관리자 긴 기록은 컨테이너 내 스크롤로 보존한다. 필드나 원장 행을
  지워서 캡처 길이를 줄이지 않는다.

## GitHub 저장 확인

연결된 GitHub API로 개발 브랜치와 main을 읽기 전용 조회했다.
개발 브랜치는 접근 가능하지만 로컬 완료 코드보다 뒤에 있다.
본 작업의 새 프리뷰 통합 코드는 원격 저장 완료로 표시하지 않는다.
main 갱신·강제 push·원격 저장소 신규 생성·운영 게시를 하지 않았다.

디자인 기본검사는 사용자 최종 디자인 승인, 실제 회원/사업자 연결,
실제 결제 승인·취소·환불 검증 또는 운영 전환 Gate 승인을 대신하지 않는다.
