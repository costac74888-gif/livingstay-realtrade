## 원본 소스와 신규 화면의 관계
새 시안의 실제 경로는 `/__mockup/preview/hs2-complete/Suite?screen=ID`다.
manifest의 `original_paths`는 원본 Python 라우트 정의에서 읽은 경로이며,
원본 HTML를 찾았지만 경로를 입증하지 못하면 빈 배열을 유지한다.
이는 운영 인증·기능을 검증했다는 뜻이 아니다.
원본 57개 HTML와 발견된 실제 탭/팝업에도 독립 ID를 부여한다.
원본 구조에서 읽은 `source_outline`은 재디자인 정보 구조의 근거로 사용한다.
