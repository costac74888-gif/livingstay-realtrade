## 공개 참고 확인 범위

실제 Chromium 1440px 공개 DOM과 computed CSS를 확인했다.
로그인·캡차 우회 또는 경쟁사 비공개 코드 접근은 하지 않았다.

- 삼삼엠투 `/guest/main`, `/guest/search`: HTTP 200. 환경의 언어/통화가
  영어/USD로 표시됐다. 검색 헤더 72px, 사진 263×175px (약 3:2),
  사진 부모의 모서리 4px, 매물 제목 16px/24px, 좌측 사진 2열과 넓은 우측 지도.
- 에어비앤비 성수 stays 및 공개 rooms 상세: HTTP 200. 공개 DOM의
  상세 제목 26px/30px, 주요 정보 제목 22px/26px 확인.
  큰 사진과 보조 사진, 본문 왼쪽·예약 영역 오른쪽 구조를 관찰했다.
  자동 번역 안내 팝업과 한글 폰트 누락으로 최초 캡처 일부가 가려졌으며,
  예약 가격은 로딩 상태라 실제 값과 상세 가격표는 확인하지 못했다.
- 일부 외부 CSS의 CSSOM 규칙은 same-origin 제한으로 읽을 수 없다.
  브라우저의 최종 computed 스타일 확인과 전체 번들 소스 검토는 구별한다.
- 경쟁사 사이트 코드의 재사용 라이선스는 확인되지 않았다.
  경쟁사 로고·문구·사진·전용 폰트·CSS/JS는 재사용하지 않는다.
  공개 화면의 배치 원칙만 참고해 홈앤스테이 시안을 직접 구현한다.

최종 캡처·클릭 검사 결과는 후속 검증 기록으로 추가한다.
