# 공매 현황조사 검증

## 구현 범위

- 기존 공매 사진·일반정보·회차표·온비드 원문 링크 아래 분석 3종, 생활형숙박시설 체크리스트, 조사 신청을 추가했다.
- 미매칭 건물의 분석은 안내로 대체하며, 조사 신청은 별도 마감 조건으로 판단한다.
- 비회원 신청, 서버 금액 계산, 입금 기한·계좌·금액·약관 스냅샷, 필수 동의 3종과 동의 시간을 저장한다.
- 요금·계좌·프로모션·정책을 DB에서 읽고 관리자 수정 내역을 보존한다.
- 관리자 신청 검색, 상태·메모·이력, 조사 약관 편집, 관리자 알림 수신함 연결을 제공한다.
- 미입금 자동취소와 입금확인은 행 잠금으로 경합을 방지한다. 프로모션 만료·약관 개정은 기존 견적을 무효화한다.
- 캠핑 렌더링, 에어비앤비 분류 키, 기존 건물 ID, 운영 DB 비밀값, 기존 분석 화면·공매 지도 코드의 변경은 없다.

## 검사 결과

- 공매 1·2차 Python 검사: 41개 통과, 추가 하위 검사 8개 통과.
- 전체 Python 검사: 800개 통과, 23개 실패, 하위 검사 67개 통과.
- 변경 전 커밋의 임시 복사본: 781개 통과, 동일한 23개 실패. 이번 변경으로 추가된 실패 없음.
- 기존 홈페이지 스모크 검사와 프런트엔드 배포 빌드 검사 통과.
- 기존 공매 브라우저 검사 통과: 목록·지역 필터·정렬·페이지, 사진 확대, 회차, 원문 링크, 카카오 공매 마커·시군구/시도 집계, 건물 공매 탭과 이력 없음 안내.
- 신규 브라우저 검사 통과: PC 1280px 및 휴대폰 390px 상세·신청, 가로 넘침 없음, 필수 동의 차단, 유형별 금액 전환, 접수 화면.
- 최초 접수 HTTP 201과 중복 없는 재시도 HTTP 200의 접수번호 표시를 모두 확인했다.
- 실제 임시 관리자 로그인으로 PC/390px 설정, 입력 저장 요청 형식, 신청 상태·메모·이력, 실제 약관 CMS와 메뉴 전환을 검사했다. 임시 관리자 계정은 삭제했다.
- 브라우저의 신청·설정 저장·상태 변경은 테스트 응답으로 가로채 외부 발송이나 실제 신청·요금 변경을 일으키지 않는다. 실제 SQL 동작은 롤백 전용 API 검사로 검증했다.
- 종합 `tests/api_test.py`는 제한 시간 내 완료되지 않았다. 진단 스택은 파트너 뱃지 테스트의 대량 건물 DISTINCT 조회에 머물렀다. 전체 API 통과로 표기하지 않는다.

## 남은 기존 검사 문제

캠핑 UI 기대값, 연결 풀 모의 객체, 통계 무효화·시작 작업 모의 객체, 일부 분석·사진·스키마 계약 검사에서 변경 전부터 동일하게 실패했다. 보호 범위를 바꾸거나 기존 검사를 삭제해서 통과시키지 않았다. 별도 작업에서 실제 오류와 오래된 기대값을 구분해 정리해야 한다.

## 화면 캡처

`attached_assets/auction-phase2/`에 상세·신청·관리자 요금 설정의 PC/390px 캡처를 저장했다. 관리자 캡처에는 Nix Chromium의 한글 글꼴 부재를 보완하는 캡처용 웹폰트를 사용했다. 앱 인증을 우회하지 않았다.
