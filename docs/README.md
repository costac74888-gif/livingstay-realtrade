## 문서 사용 원칙

- 운영 판단은 가장 최근 기준일의 `현행` 문서를 우선한다.
- 보고서는 특정 시점의 증거이며 현행 정책을 대신하지 않는다.
- 새 정책이나 매뉴얼을 만들면 중앙 문서대장과 CSV를 함께 갱신한다.
- 정책 파일명에는 버전과 기준일을 넣는다.
- 다운로드용 PDF·DOCX·HTML은 `exports/`에 둔다.
- 비밀키, 토큰, DB 접속 문자열과 개인정보는 문서에 기록하지 않는다.

## 다운로드 파일

`exports/`에서 `HOME_AND_STAY_*_V버전_날짜` 형식의 PDF·DOCX·HTML을 찾을 수 있다.
