## 1. 목적과 산출물 경계

이 문서는 종합매뉴얼 본문을 작성하기 전에 권위 문서, 역사자료, 실제 실행 계약, 용어와 번호 체계를 고정한다. 후속 문서는 이 기준을 반복해서 새로 판단하지 않고 같은 구조와 용어를 사용한다.

이 문서에서 확정하는 것은 다음과 같다.

1. 기존 정책·매뉴얼·보고서의 분류와 권위
2. 문서와 코드 사이의 중복·누락·상충 항목 및 최종 적용 기준
3. 종합매뉴얼 장·절 번호와 문서별 작성 순서
4. 캠핑 시설수와 사이트 4분류의 편찬 기준
5. 공통 용어, 표기, 검증 증거와 완료 기준

종합매뉴얼 본문 전체 작성, 운영 데이터 변경, 기존 정책 문서 삭제는 이 문서의 범위가 아니다.

## 2. 권위와 충돌 해결 순서

운영 판단과 종합매뉴얼 작성에는 다음 순서를 적용한다.

1. 법령, 정보주체 동의 또는 별도 계약 중 더 엄격한 기준
2. 공개·개인정보 영역은 POL-EXPOSURE-001
3. 데이터 수집·검증·승격·갱신 영역은 POL-DATA-003
4. 사진 영역은 MAN-PHOTO-001
5. 이 문서에서 확정한 편찬 기준과 용어
6. 현재 코드·워크플로·테스트에서 확인한 실제 실행 계약
7. 보조 가이드
8. 대체 문서와 역사 보고서

문서와 코드가 다르면 코드가 자동으로 최종 정책이 되지 않는다. 공개 확대, 대량 반영 또는 운영 전환을 멈추고 현행 정책에 맞게 문서나 코드를 먼저 일치시킨다. 역사 보고서의 수치와 당시 판정은 증거로 보존하되 현재 절차를 지시하지 않는다.

## 6. 캠핑 편찬 기준

### 6.1 시설수 산식과 순서

시설수는 다음 순서로 계산한다.

1. 영업상태가 활성인 캠핑 원장만 선택한다.
2. `applied_building_id`가 있는 행은 동일 건물당 하나의 건물형 시설로 묶는다.
3. 건물 연결이 없는 행은 대지형·사업장 시설 후보로 본다.
4. 미연결 행은 주소와 정규화 상호가 모두 일치할 때만 원본 간 같은 시설로 묶는다.
5. 연결 시설과 같은 신뢰 키를 가진 미연결 행은 중복으로 제외한다.
6. 신뢰 키가 없는 미연결 행은 과도하게 합치지 않고 관리번호별 시설로 보존한다.
7. 중복 원본에서는 사이트 정보가 가장 완전한 대표행을 선택하며 여러 행의 사이트 수를 더하지 않는다.

```text
정상영업 캠핑 시설수
= 활성 건물형 고유시설
  + 활성 미연결 대지형 고유시설
  - 건물형·대지형 사이의 신뢰 가능한 중복
```

휴업·폐업 등 비활성 원장은 삭제하지 않지만 공개 시설수와 사이트수에서 제외한다.

### 6.2 사이트 4분류

| 종합매뉴얼 표기 | 내부 의미 |
|---|---|
| 일반야영 사이트 | `camping_general_site_count` |
| 자동차야영 사이트 | `camping_auto_site_count` |
| 글램핑 사이트 | `camping_glamping_site_count` |
| 카라반 사이트 | 설치 카라반과 개인 카라반 사이트의 합 |

네 수치는 서로 대체하지 않고 각각 보존한다. `캠핑 사이트 합계`는 네 수치의 합이다. 캠핑 사이트 수를 숙박 객실수로 표현하거나 일반 숙박 신고율 산식에 넣지 않는다.

### 6.3 시설 유형과 품질지표

- 한 유형만 양수이면 해당 단일 유형이다.
- 둘 이상 양수이면 실제 복합(`confirmed_mixed`)이다.
- 값이 없거나 모두 0이면 미확인(`unknown`)이다.
- 공개 화면에서 미확인을 복합 범주에 함께 보일 수 있어도 내부 데이터와 품질 보고서는 실제 복합과 미확인을 분리한다.
- 정상영업 신고시설의 신고율과 사이트 수 확보율을 구분한다. 사이트 수 확보율은 원본 커버리지 품질지표이지 신고율이 아니다.

## 9. 공통 용어와 작성 기준표

### 9.1 공통 용어

| 권장 용어 | 정의 | 사용하지 않거나 구분할 표현 |
|---|---|---|
| 원본 | 외부 기관·공급자가 제공한 변경 전 자료 | 정규화 결과와 혼용 금지 |
| 원장 | 관리번호 등 논리 키별 이력을 보존하는 내부 기록 | 공개 목록과 동일시 금지 |
| staging | 운영 반영 전 개발 DB의 격리 적재 영역 | 운영 원장 직접 적재와 구분 |
| 승인 payload | 검증·검토 후 고정한 변경분 | 개발 DB 전체 복사 아님 |
| manifest | 원본 지문·기준선·승인 계보를 묶은 반영 증거 | 단순 파일목록 아님 |
| 운영 반영 | 승인 변경분을 운영 DB에 멱등 적용 | Publish와 구분 |
| 활성 | 해당 지표의 내부 활성 판정 함수를 통과한 상태 | 문맥 없이 “정상”과 혼용 금지 |
| 비활성 | 휴업·폐업·취소·말소 등 공개 제외 상태 | 삭제와 구분 |
| 시설수 | 중복 제거한 실제 서비스 시설 단위 | 신고행 수·건물 수와 구분 |
| 신고수 | 관리번호 등 원장 단위 건수 | 시설수와 구분 |
| 사이트수 | 캠핑 4분류 사이트 수 합계 | 객실수와 구분 |
| 실제 복합 | 둘 이상의 확인된 유형이 함께 존재 | 미확인과 구분 |
| 미확인 | 원본 수량이 없거나 유형을 확정할 수 없음 | 내부에서 복합으로 저장 금지 |
| 공개 projection | 역할에 허용된 최소 응답 필드 집합 | 관리자 객체 재사용 금지 |
| 기준선 | 변경 전 비교·중단·복구 판단용 값과 증거 | 목표값과 구분 |
| dry-run | 쓰기 없이 예상 변경과 중단조건을 검증하는 실행 | 승인·실제반영과 구분 |
| rollback | 마지막 정상 상태로 되돌리는 검증된 절차 | 단순 재실행과 구분 |

### 9.2 작성 규칙

| 항목 | 필수 기준 |
|---|---|
| 장·절 | 이 문서의 번호를 유지하고 새 항목은 기존 의미를 재번호화하지 않는 범위에서 추가 |
| 상태 | 공개 상태, 내부 원장 상태, 작업 실행 상태를 서로 다른 표로 작성 |
| 환경 | 모든 명령·버튼에 개발/운영, 읽기/쓰기, 자동/수동을 표시 |
| 데이터 단위 | 행·신고·시설·건물·객실·사이트를 표 제목과 산식에 명시 |
| 수치 | 기준일·대상 DB·필터·중복 제거 단위가 없는 수치는 본문 기준으로 사용 금지 |
| 공개범위 | 공개 가능과 관리자 전용을 분리하고 애매하면 비공개 |
| 실패 | 전제조건, 중단조건, 재시도, 부분 commit 확인, rollback을 함께 기술 |
| 외부 API | 원본·서비스키 버킷·할당량·pagination·완료 판정·오류 마스킹을 명시 |
| 코드 인용 | 함수명만 권위로 삼지 않고 정책 의미와 검증 테스트를 함께 적음 |

| 비밀·개인정보 | 실제 값·원본 표본·접속 문자열을 문서와 검증 로그에 복사하지 않음 |
| 중복 서술 | 권위 절 한 곳에 전문을 두고 나머지는 문서 ID·절 번호로 참조 |
