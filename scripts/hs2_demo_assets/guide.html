테스트 계정 제공 방법

가상 체험 계정 101이 자동 연결됩니다. 비밀번호 입력은 필요 없습니다. 소비자와 운영자 역할은 같은 격리 체험 계정에 미리 연결되어 있습니다. 실제 회원 로그인·휴대폰/사업자 본인확인 검증을 대체하지 않습니다. 실제 이메일·전화번호·소유자 정보를 입력하지 마세요.

이 Preview는 체험자 간 같은 데이터를 공유합니다. 새로고침해도 예약 변경은 유지되지만 서버가 재시작하면 매물·예약은 처음 상태로 초기화됩니다.

테스트 순서

  1. 메인에서 성수동1가·2가의 가상 매물 사진, 면적, 인원, 편의시설과 기준 요금을 비교합니다.
  2. 지역에 성수를 입력하고 방·면적·인원·옵션·유형을 바꿔 검색합니다. 숙박은 1박부터, 비숙박 단기임대는 7일 또는 달력 월 단위입니다.
  3. 입실·퇴실을 선택하면 실제 테스트 가격 원장으로 기간 총액을 계산합니다. 주·월 금액을 임의로 1박 가격으로 환산하지 않습니다. 일부 가상 매물은 다음주 3일이 마감되어 있습니다.
  4. 매물을 선택해 상세 사진·설명·달력·기간 총액을 확인하고 견적 확인 → 예약 신청을 진행합니다. 마감 날짜, 최소 체류기간, 인원 초과, 만료된 견적도 테스트하세요.
  5. 내 예약에서 신청 상태를 확인합니다. 같은 화면의 운영자 모드에서 해당 신청을 승인합니다.
  6. 승인된 예약의 결제 조건 확인 → 모의 결제를 진행합니다. 내 예약과 운영자 대시보드에서 상태를 비교합니다. 미리 생성된 모의 결제 예약도 1개 있습니다.
  7. 지도 검색에서 매매·영업권 양도·공매 레이어를 켜 각 3개 항목의 상세 요약을 비교합니다. 이 항목들은 숙박 예약 대상이나 실제 계약/사건이 아닙니다.

결제와 미완료 범위

현재 결제는 OwnedSandbox 모의 처리입니다. 실제 토스 테스트 API가 아닙니다. 이 개발 서버는 토스 키를 받지 않고 외부 전송을 차단합니다. 작업공간에 키가 있다는 사실만으로 토스 테스트 연결 성공이라고 표시하지 않습니다. 실제 결제·정산·환불 지급·문자·이메일은 실행하지 않습니다.

지도 메인은 기존 카카오 SDK의 실제 지도·타일과 우측 도구를 사용합니다. 매물 23개와 그 좌표는 성수동 테스트용 가상 데이터이며 실제 주소·소유자·GPS 검증 결과가 아닙니다. 매매·양도·공매는 레이어와 상세 요약 체험만 제공하며 실제 거래/입찰을 제공하지 않습니다. 다시 제공된 흰색·파란색 목업을 기준으로 글자를 키웠습니다. 상세·운영자 화면의 세부 배치는 아직 목업과 차이가 있으며, 실제 관광 데이터랩 원장은 이 격리 Preview에 연결하지 않았습니다.
