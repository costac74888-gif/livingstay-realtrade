name: 유료 멤버십 제공 범위
description: 행정운영 무료 요약과 상세 원장·공매 현황조사의 유료화 경계, 가격 승인 원칙
---

행정운영 요약(신고율·신고 호실·사업장 요약·담당부처)은 운영정보 탭의 예약 안내 바로 아래, 관광통계 위에 둔다. 상세 공식 영업·운영 기록과 공매 현황조사 정보는 유료 멤버십 대상이며 공매 기본 공고 정보는 공개한다.

**Why:** 사용자가 첨부 화면으로 요약의 이동 위치를 지정하고, 상세 공식 기록과 공매 현황조사를 멤버십으로 유료화하되 우선 이동·비노출부터 수행하라고 요청했다.

**How to apply:** 잠금은 화면뿐 아니라 API 응답에도 적용한다. 일반 가입·파트너·운영자 사업장 역할을 유료 구독으로 간주하지 않는다. 기존 관리자 업무·자기 사업장 관리와 접수된 조사 신청은 보존한다. 가격·결제·구독 권한은 사용자 승인 후 적용하며 제안 가격을 확정 정책으로 표시하지 않는다.

멤버십 월 요금은 29,000원이며 현장확인은 제공 범위에서 제외한다. 영업신고·위탁운영·관리비 확인의 제공 횟수와 부가세 포함 여부는 별도 승인 대상이다.

**Why:** 사용자가 2026-10-05 “멤버쉽은 월 29000원으로하고 … 현장확인은 없애자”라고 결정하고 확인 횟수는 추천을 요청했다.

**How to apply:** 가격을 더 이상 미정으로 취급하지 않되 결제 활성화 승인과 구분한다. 현장 방문 상품·추가요금을 새 멤버십에 포함하지 않는다. 추천한 횟수·이월 정책은 사용자의 확정 전에는 승인 정책으로 구현하지 않는다.
