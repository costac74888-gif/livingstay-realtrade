---
name: 분석 슬라이더 입력 경계
description: 임대·운영 분석의 URL 복원 상한과 월세 중심 고정 원칙
---

공유 링크·탭 간 전달·직접입력은 화면 표시 직전이 아닌 **값을 수용하기 전** 같은 절대 상한으로 검증한다. 잘못된 공유 URL 수치는 버리고 해당 파라미터만 지우며, 유효한 건물 기준값이 있으면 잘못된 매입가·월세만 안전한 기본값으로 다시 채운다.

**Why:** 상한 없는 과거 링크가 비정상적으로 큰 금액을 슬라이더에 복원해 사용자가 범위를 조작할 수 없었다. 나중에 화면만 잘라도 계산·공유 상태는 이미 오염된다.

**How to apply:** 신규 시나리오 공급 경로가 생기면 복원 지점에서 상한 검증을 선행하고, 계산에 쓰는 정확한 수치와 슬라이더 표시 수치를 구별한다.

월세·비교월세의 범위 중심은 건물·면적·탭 진입이나 직접입력 확인처럼 명시된 재설정 시점에만 바꾼다. 슬라이더 드래그나 매입가 변경은 현재값을 바꿀 수 있어도 중심을 재설정하지 않는다.

**Why:** 매수가 변경 때마다 현재 월세를 새 중심으로 삼으면 월세 최대를 반복 선택할 때 범위가 계단식으로 계속 증가한다.

**How to apply:** 종속 슬라이더 갱신과 범위 중심 갱신을 별도 이벤트로 취급하고, 반복 드래그·매수가 변경 회귀 테스트를 유지한다.
