---
name: JS 소스 추출 테스트
description: 큰 브라우저 스크립트에서 특정 함수만 VM으로 실행하는 테스트의 안전한 시작점 선택
---

함수 본문을 문자열로 찾아 VM에서 격리 실행하는 테스트는 `function loadDataLab` 같은 접두 검색 대신 `function loadDataLab(key`처럼 대상의 전체 시그니처를 시작점으로 사용한다.

**Why:** 접두 이름을 공유하는 새 함수가 앞에 추가되면 테스트가 더 이른 함수를 선택해 무관한 전역 상태 오류를 내고, 실제 회귀 원인을 가린다.

**How to apply:** 시작·종료 인덱스가 예상 함수 선언과 일치하는지 먼저 검증하고, 격리 컨텍스트에는 그 함수가 직접 참조하는 의존성만 스텁으로 제공한다.
