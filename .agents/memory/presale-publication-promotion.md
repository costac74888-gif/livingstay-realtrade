description: 분양 신청, 프로젝트 진행 상태, 공개 수명주기, 유료 프로모션 활성 조건을 혼동하지 않기 위한 운영 원칙
---

분양중·분양예정·완판이라는 사업 진행 상태와 초안·게시·철회라는 공개 상태를 별도로 관리한다. 유료 노출도 프로젝트의 단순 불리언이 아니라 승인 상태와 시작·종료 기간을 가진 별도 기록으로 판단한다.

분양사가 제출한 원본 신청과 개인정보·증빙은 공개 프로젝트와 분리하고, 관리자 승인 트랜잭션에서만 프로젝트 초안으로 전환한다. 신청·직접 등록·승인은 같은 건물 단위 잠금 아래에서 서로의 활성 상태를 확인한다.

**Why:** 세 상태를 한 필드나 관리자 체크박스로 합치면 미래 공개 예약, 완판 숨김, 광고 만료·취소가 서로 덮어쓰여 만료된 광고나 비공개 프로젝트가 노출될 수 있다. 신청을 프로젝트에 바로 저장하면 심사 전 개인정보가 공개 경로에 섞이고 동시 등록 경쟁으로 승인 불가능한 신청이 남을 수 있다.

**How to apply:** 공개 목록·상세·배너 이미지 제공 모두 서버 현재 시각을 기준으로 프로젝트 공개 기간과 진행 상태, 프로모션 승인 기간을 함께 검사한다. 관리자 화면의 표시값만 믿지 않는다. 새 신청·등록 경로도 건물별 단일 소유 규칙과 비공개 신청 경계를 함께 지킨다.
