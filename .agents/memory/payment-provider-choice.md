---
name: 토스 결제수단 유지
description: 프로젝트의 지정 결제수단과 대체 공급자 변경 금지
---

이 프로젝트의 지정 결제수단은 토스다. 사용자는 토스 테스트키를 발급받았다고
명시했으며, 다른 결제수단을 제안받은 뒤에도 토스로 진행한다고 재확인했다.
키 값 자체는 기록하거나 채팅으로 요청하지 않는다.

**Why:** 공급자 선택은 이미 확정된 제품 요구사항이다. 지원되는 절차의
제약 때문에 다른 공급자로 임의 변경하면 사용자 요청과 달라진다.

**How to apply:** 토스가 가능한 작업 절차인지 먼저 확인한다. 제약이 있으면
정확히 알리고, Stripe·Whop 등으로 자동 교체하거나 모의 결과를 실제 토스
검증으로 표시하지 않는다. 공급자 변경에는 별도 명시적 요청이 필요하다.

키 종류는 승인 API 사용 여부가 아니라 선택한 SDK 상품으로 결정한다.
2026-10-11 확인한 공식 결제창형 안내는 주문서형·결제창형 키 쌍을 사용하며,
API 개별 연동 키를 요구하는 다른 결제창 SDK 안내와 혼동하지 않는다.
문서용 테스트 키와 사용자 상점의 테스트 키도 구별한다.

**Why:** 같은 ‘결제창’ 명칭의 공식 안내에서도 상품에 따라 키 종류가 다르다.
서버 승인 API를 호출한다는 이유만으로 API 개별 연동 키를 선택하면 잘못된
키 쌍을 안내할 수 있다.

**How to apply:** SDK 상품·공식 안내와 키 쌍을 함께 확인한다.
