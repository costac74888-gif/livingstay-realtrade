---
name: 숙박운영분석 시나리오 경계
description: 임대·운영 탭 간 조건 공유와 건물 변경 시 증빙·가정값 격리 원칙
---

같은 건물에서 임대수익분석과 숙박운영분석을 오갈 때 매입가·월세를 공유한다. 그러나 건물이 바뀌면 이전 건물의 예약실적표에서 나온 ADR·OCC·기간과 매입가·월세를 새 건물의 실적으로 이어받지 않는다. 새 건물의 검증된 자료로 다시 가정하거나, 그 건물에 명시적으로 지정된 공유 시나리오만 복원한다.

**Why:** 업로드 실적은 건물에 귀속된 근거이며, 이전 건물의 숫자를 다른 건물명으로 표시·인쇄·공유하면 근거와 수익 판정이 잘못 연결된다. 반면 같은 건물 안에서는 임대와 위탁운영 조건을 비교해야 하므로 탭 이동만으로 조건을 지우면 안 된다. 임대·운영 양쪽의 지연 입력 갱신은 한쪽만 취소해도 다른 쪽의 예약 콜백이 이전 건물의 URL 조건을 다시 써 넣을 수 있다.

**How to apply:** 건물 식별자가 바뀌는 흐름과 비동기 응답·디바운스 콜백의 대상 식별자를 양쪽 분석 화면 모두에서 확인한다. 공유 링크 복원은 링크가 가리키는 건물에만 적용하고, 일반 탭 전환에서는 같은 건물의 최신 사용자 입력을 우선한다.
