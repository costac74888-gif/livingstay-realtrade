---
name: 운영자 등록 숙박정보 표시
description: 운영자가 직접 등록한 숙박 운영정보와 인증 표시의 공개 정책
---

운영자 편의시설과 인증·선정 표시는 서버의 고정 선택지만 저장하며, 별도 관리자 심사 없이 즉시 공개한다. 자유 입력 인증명은 허용하지 않는다. 운영자 입력 정보나 인증 표시가 하나라도 공개되면 운영정보 탭 맨 마지막에 운영자 직접 등록 정보이며 실제와 다를 수 있다는 고지를 표시한다.

**Why:** 매번 관리자 검수를 하기 어렵다는 운영 정책과, 공공 원본 정보로 오인하게 만들지 않아야 한다는 신뢰성 요구를 함께 충족해야 한다.

**How to apply:** 새 운영자 입력 항목을 추가할 때 서버 allowlist와 화면 선택지를 함께 갱신하고, 공공 원본 값과 운영자 입력값의 출처를 분리한다. 운영자 입력 표시 여부 계산에도 새 항목을 포함한다.
