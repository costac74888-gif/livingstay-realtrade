---
name: 인증 응답 순서
description: 정상 로그인 뒤 회원 전용 화면으로 돌아가는 비동기 인증 응답 경합과 검증 범위
---

인증 화면 상태는 가장 최근에 요청한 인증 조회를 기준으로 적용한다. 이전
조회 응답이나 이전 조회의 네트워크 실패가 현재 계정 상태를 바꾸면 안 된다.
최신 조회 자체의 실패는 계속 비인증 상태로 처리한다.

**Why:** 페이지 초기 익명 조회가 로그인 후 조회보다 늦게 도착하는 순서를
재현했을 때, 정상 로그인 상태가 미로그인으로 되돌아갔다. 서버 세션이
정상이라는 사실만으로 모바일 회원 화면의 인증 상태도 정상이라고 볼 수 없다.

**How to apply:** 로그인·로그아웃뿐 아니라 계정·사업자 역할 전환도 응답
도착 순서를 바꿔 검사한다. 이전 실패를 무시하는 보호가 최신 인증 실패까지
숨기지 않는지 확인한다. 사업자 인증과 일반회원 전용 기능의 허용 범위는
별개이며 이 경합 수정으로 권한을 넓히지 않는다.
