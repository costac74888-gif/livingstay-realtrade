name: 주간 이메일 공개 데이터 원칙
description: 주간 이메일의 공개 숫자 단일 원본, 빈 상태, 원장 선점, 관리자 검수본 원칙
---

주간 이메일의 공통 숫자는 운영 홈페이지가 사용하는 공개 API 응답을 그대로 요약하고 이메일 전용 SQL·재계산·fallback을 만들지 않는다. 공개 데이터가 없거나 준비 중이면 이메일 전체를 중단하지 않고 해당 영역을 숨기거나 “이번 주 신규 실거래가 없습니다”처럼 정상 empty state를 표시한다. 개인화는 공개 숫자에 회원 관심단지·의뢰만 결합한다. 기능 소개는 기존 관리자 저장값을 그대로 사용한다.

**Why:** 이메일 전용 산식·fallback은 운영 화면과 다른 숫자를 만들 수 있고, mock 기반 검증과 폐기된 자식 프로세스 로그는 실제 DB 발송 실패를 숨길 수 있다.

**How to apply:** 주간 발송 경로의 SQL·공통 통계·관리자 사본을 바꿀 때 적용한다. 홈페이지 DataLab 공개 라우트 외의 공통 숫자 조회를 추가하지 않는다. 공개 API warming·빈 응답·예외는 숫자를 새로 만들지 않고 empty state로 처리한다. 수신자 원장 SQL은 실제 DB rollback 검사로 확인하고 자식 프로세스 stdout/stderr는 실행별 로그에 보존한다.
