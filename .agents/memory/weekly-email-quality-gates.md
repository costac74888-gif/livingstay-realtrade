---
name: 주간 이메일 발송 품질 게이트
description: 주간 이메일의 원장 선점, 공통 통계 검증, 관리자 검수본 구분 원칙
---

주간 이메일은 공통 지표가 허용 범위를 벗어나면 해당 값만 숨기고 계속 보내지 말고 전체 발송을 중단한다. 발송 원장 선점 SQL은 문자열 검사만으로 충분하지 않으며 실제 PostgreSQL 트랜잭션에서 실행한 뒤 rollback하는 검증을 포함한다. 관리자 사본은 회원별 관심단지·의뢰가 없는 검수본임을 본문에서 명시한다.

**Why:** SQL 문자열 안의 리터럴 `%`가 psycopg2 바인딩 기호로 해석되어 모든 일반회원 선점이 실행 전에 실패했지만, mock cursor 테스트와 폐기된 subprocess 로그 때문에 파트너 발송만 성공한 원인을 바로 볼 수 없었다. 검증되지 않은 축약 신고율과 빈 개인화 영역도 정상 콘텐츠처럼 발송됐다.

**How to apply:** 주간 발송 경로의 SQL·공통 통계·관리자 사본을 바꿀 때 적용한다. 수신자 원장 INSERT/재시도는 실제 DB rollback 검사로 확인하고, 신고율은 중복 제거와 건물별 cap을 적용한 공식 집계만 사용하며 0~100% 밖이면 발송을 실패 처리한다. 자식 프로세스 stdout/stderr는 실행별 로그에 보존한다.
