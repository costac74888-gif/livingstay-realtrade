---
name: 백그라운드 프레임 준비 경계
description: 비활성 브라우저 탭의 animation frame을 완료 신호로 무기한 기다리지 않는 원칙
---

비활성 탭에서도 완료되어야 하는 공통 표시 처리는 animation frame에만 의존하지 않는다.
브라우저 검사 또한 DOM 출현·글꼴 로드·표시 스타일 정착을 각각 확인하며 프레임 대기에 상한을 둔다.

**Why:** 병렬 PC/모바일 캡처 중 백그라운드 탭의 프레임이 중단되어 검사가 멈췄고,
늦게 들어온 예약·알림 원장 텍스트가 공통 크기·색상 적용 전에 캡처되는 현상이 관찰됐다.

**How to apply:** 프레임 예약에는 중복 실행을 막는 제한 시간 대안을 두고, 검사에서
대기 시간을 늘리는 대신 실제 표시 준비 조건을 확인한다. 프레임이 실행되지 않는
상태와 스타일 요구 미충족을 구분한다.
