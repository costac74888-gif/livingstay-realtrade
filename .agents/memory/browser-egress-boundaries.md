---
name: 브라우저 검사 네트워크 경계
description: 페이지 경로 모의 처리와 실제 전송 차단을 별개로 검증하는 이유.
---

페이지·컨텍스트 경로 모의 처리만으로 외부 전송 차단을 보장하지 않는다.
검사가 페이지별 `route.continue`를 설치하면 컨텍스트 경로 가드를 건너뛸
수 있다. 리디렉션과 APIRequestContext까지 같은 소유 출처 경계에서 막아야 한다.

**Why:** 외부 접근 탐지용 로컬 서버를 둔 실제 브라우저 검사에서, 페이지
경로 처리만 막았을 때 준비 요청과 리디렉션이 다른 전송 경로를 사용했다.

**How to apply:** 네트워크 경계는 필수 프록시 또는 동등한 전송 계층에서
검증한다. 탐지 서버 수신 건수 0을 확인하고, 금지된 요청 실패를 PASS로
바꾸지 않는다. 기존 HS2의 Node 전체 차단 가드는 별개로 유지한다.
