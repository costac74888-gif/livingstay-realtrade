---
name: 대표 영업신고 선정
description: 한 건물에 여러 활성 영업신고가 연결될 때 첫 화면 대표 사업장을 정하는 기준
---

한 건물에 활성 영업신고가 여러 개면 공식 신고 객실수가 가장 많은 사업장명을 운영정보 첫 화면과 목록 최상단의 대표로 사용한다. 객실수가 없거나 같은 신고끼리는 원장의 기존 순서를 유지한다.

**Why:** 대표 명칭은 원장 종류보다 실제 신고 운영 규모를 반영해야 사용자가 건물의 주된 운영 사업장을 먼저 이해할 수 있다.

**How to apply:** 건물 상세, 공유 정보, 검색 결과 등에서 대표 운영정보를 선택할 때 동일한 객실수 우선 기준을 사용한다. 캠핑 사이트 수는 객실수로 간주하지 않는다.
