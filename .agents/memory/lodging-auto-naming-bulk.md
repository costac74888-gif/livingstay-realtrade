---
name: 숙박업 자동명명 대량 갱신
description: 기존 미확정 일반숙박 건물의 영업신고 기반 자동명명을 운영 DB에 대량 적용할 때의 성능 제약과 처리 원칙.
---

대량 자동명명은 대상 건물을 하나씩 조회하지 말고, 주소 정규화 키를 모아 활성 영업신고를 한 번에 조회한 뒤 도로명 우선·지번 보조로 후보를 선택하고 batch UPDATE한다.

**Why:** 운영 DB의 미확정 일반숙박 대상은 1만 건 이상이다. 건물별 신고 조회는 원격 DB 왕복이 누적되어 작업 실행 제한을 넘기며, 함수가 마지막에만 커밋하면 완료 전 종료된 작업은 유효한 반영 결과도 남기지 못한다.

**How to apply:** 전체 백필 완료 후 또는 정규화 재계산 뒤 자동명명을 실행할 때는 일괄 경로를 유지한다. 활성 후보가 없으면 기존 자동명은 바꾸지 않고, 공식·사용자 확정명은 항상 제외한다.
