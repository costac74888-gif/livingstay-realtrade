---
name: 공매 초기 진입과 인증 갱신
description: 늦게 끝나는 로그인 상태 확인이 선택 공매와 상세 탭을 초기화하지 않게 하는 원칙
---

계정 상태나 관심단지 정보 갱신으로 상세 화면을 다시 그릴 때도 선택 공매와 사용자가 보고 있던 탭을 유지한다.

**Why:** 이미 연결된 공매로 처음 진입하면 건물 화면이 로그인 상태 확인보다 먼저 열린다. 이후 인증 이벤트의 일반 건물 재갱신이 공매 문맥을 버리면 세 탭이 두 탭으로 바뀐다. 미연결 공매의 조회 대기 후 연결 검사에서는 인증 확인이 먼저 끝나 이 경합이 보이지 않았다.

**How to apply:** 지연된 인증 이벤트와 이미 연결된 공매의 초기 진입도 검사한다. 전체 공매 이력이 늦거나 비어 있어도 서버가 확인한 현재 선택 물건은 유지하며, 뒤늦은 응답이 사용자의 탭 선택을 되돌리지 않게 한다.
