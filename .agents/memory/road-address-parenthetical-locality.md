---
name: 도로명 괄호 지역 보정
description: 건축물대장과 표준 도로명주소 사이의 괄호 읍·면·동 처리 원칙
---

도로명 매칭 키를 만들 때 괄호 안 일반 법정동은 삽입하지 않는다. 도로명 본문에서 실제로 생략될 수 있는 읍·면만 도로명 앞에 복원한다.

**Why:** 건축물대장의 `(성곡동)` 같은 참고 표기를 키에 넣으면, 이를 포함하지 않는 공인중개사 표준 도로명주소와 동일한 도로명·건물번호인데도 매칭이 끊긴다. 반면 `(동명면 기성리)`처럼 본문에서 읍·면이 빠진 주소는 읍·면 복원이 필요하다.

**How to apply:** 도로명 주소 정규화와 그 파생 키 재생성 시 같은 규칙을 사용한다. 정규화 규칙이 바뀌면 기존 저장 파생 키도 재계산하고, 실제 목록과 상세 API를 함께 검증한다.
