---
name: 상가정보 API 수집 우선순위
description: 단지부동산 집중 수집과 일반 상가·실시간 조회의 공유 API 한도 정책
---

단지부동산과 일반 상가 수집은 같은 상가정보 API 서비스키를 사용한다. 별도 API처럼 한도를 합산하면 안 된다.

**Why:** 과거 배치가 한도를 소진해 사용자 실시간 상가 조회가 차단됐다. 단지부동산을 별도 1,000회 공급자로 취급했던 과거 정책도 같은 키의 실제 사용 경로와 맞지 않는다.

**How to apply:** 두 수집기의 HTTP 요청·추가 페이지·재시도는 하나의 공유 배치 예산으로 제한하고, 체크포인트 초기화가 호출 예산을 초기화하지 않도록 한다. 정책 변경 당일에는 변경 전 호출량을 새 요청 원장에 보수적으로 이월한다.

다른 자료는 많이 수집됐으므로 단지부동산 수집을 우선한다. 배치 8,000회 중 단지부동산 7,500회, 일반 상가 500회를 배정하고 실시간 1,500회·수동 여유 500회를 남긴다.

**Why:** 사용자가 2026-10-03 단지부동산 수집에 집중하고 하루 건수를 확대하도록 요청했다. 사용자 조회를 희생하지 않고 불균형한 수집 진척을 개선하려는 배정이다.

**How to apply:** 관리자 실행·정기 실행·직접 실행에서 같은 배정을 적용한다. 임의로 공급자 한도를 키우거나 다른 자동 수집 전체를 중단하지 않는다. API 연결 오류는 빈 결과와 구별해 미확인 건물로 남겨야 한다.
