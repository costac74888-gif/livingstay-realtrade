---
name: 실행 설정 원문 보존
description: 터미널 출력의 CRLF를 파일 원문으로 취급하면 설정 전체가 불필요하게 변경되는 문제
---

터미널 출력은 파일의 원문 바이트와 같다고 가정하지 않는다. 설정 원문을 왕복할 때 줄바꿈·제어문자와 의미상 동일성을 모두 확인한다.

**Why:** CodeExecution의 shellExec로 얻은 Git 원문 출력에는 CRLF가 붙어, 검증된 TOML 교체라도 LF 원본 전체가 변경된 것으로 나타났다. 실행 명령을 복구하면서 관계없는 설정 차이까지 만들 수 있다.

**How to apply:** 설정 수정은 검증된 교체 경로를 사용하고, 터미널 출력으로 구성한 내용은 원문 줄바꿈과 대조한다. 복구 완료 판정은 프로세스 기동뿐 아니라 설정 diff가 의도한 범위인지도 확인한다.
