---
name: 건물전체 매물 체크리스트 공개 범위
description: 건물전체 매물 실사 체크리스트가 제한공개 익명성을 훼손하지 않도록 하는 공개·저장 원칙.
---

공개 체크리스트 API는 **직거래·건물전체·공개 범위(public)** 매물에만 제공한다. 제한공개 매물에는 체크리스트의 자동 건물값도 제공하지 않고 404로 처리한다. 다만 판매자가 공개용으로 직접 작성한 매물 설명은 제한공개 카드에 제공할 수 있다. 로그인 회원의 체크 상태는 사용자·매물·항목별로 서버에 저장하고, 비로그인 상태는 매물별 브라우저 저장소로만 유지한다.

**Why:** 제한공개 카드에서 숨긴 정확한 건물 식별 정보가 연면적·용도지역·인근 경쟁시설 같은 자동값 조합으로 다시 유추될 수 있다. 체크 진행 상태를 익명 사용자와 서버 계정에 섞으면 개인 데이터와 로그인 전환 시점의 상태가 불명확해진다.

**How to apply:** 공개 범위가 제한된 매물에 새 보조정보·상세 API를 추가할 때는 그 정보만으로 건물이 재식별되지 않는지 먼저 검토한다. 판매자 입력 설명 외의 정확한 주소·좌표·사진·자동 건물 보조정보는 계속 제거한다. 로그인 전용 체크 상태는 유효한 공개 매물인지 서버에서 재확인한 뒤 저장한다.
