---
name: 관광 급등동네 건물 매칭
description: 관광데이터랩 행정동 급등 순위를 건물 상세에 안전하게 연결하는 기준
---

급등 뱃지는 건물의 법정동과 관광데이터랩 행정동 이름이 정확히 같거나, 건물 좌표의 행정동이 외부 행정구역 응답으로 유일하게 검증됐을 때만 표시한다. 숫자 분동을 제거해 합치는 방식은 사용하지 않는다. 서로 다른 관광 지표는 각각의 자료기간을 따로 표시한다.

**Why:** `덕풍3동`을 `덕풍동`으로 축약하면 덕풍1·2동 건물에도 TOP 순위가 붙을 수 있다. 또한 방문·검색·소비·급등 자료의 최신 기간은 서로 달라 하나의 공통 기간처럼 표시하면 안 된다.

**How to apply:** 숫자 분동은 좌표와 시·군·구까지 일치하는 유일한 행정동 검증값만 건물 교차표에 저장한다. 미응답·지역 불일치·복수 결과는 숨긴다. 새 지표를 상세 카드에 추가할 때도 값과 함께 해당 지표의 원본 기간을 노출한다.
