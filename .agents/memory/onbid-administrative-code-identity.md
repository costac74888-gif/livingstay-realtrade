---

공매의 과거 행정구역명만 보고 폐지 코드를 우선 사용하거나, 한 번의 0건 응답으로 건물이 없다고 판단하지 않는다. 현재·과거 공식 법정동 원본을 대조하고, 동일 광역지역 안에서 전체 읍면동 이름이 유일하게 대응할 때만 현재 코드와 주소를 동등하게 취급한다.

**Why:** 2026-10-05 실조회에서 인천 서구의 과거 코드로는 0건이었지만, 서해구의 현재 코드로는 동일 지번의 숙박건물 대장이 반환됐다. 이는 전남광주 통합 신코드 대신 폐지 코드를 써야 했던 사례와 반대 방향이므로, 공급자가 항상 신코드 또는 항상 구코드를 쓴다고 가정하면 안 된다.

**How to apply:** 공식 후보가 복수이면 자동 치환하지 않는다. 공적 지번·도로명·동·대장 식별자를 확인하고, 이미 저장된 동일 대장 식별자는 행정구역 표기가 달라도 재사용해 중복 건물을 만들지 않는다. 개발에서의 조회 성공을 운영 중계 설정이나 운영 저장 성공의 증거로 해석하지 않는다.
