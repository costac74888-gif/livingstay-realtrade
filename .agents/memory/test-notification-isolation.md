---
name: 자동검사 외부 알림 차단
description: 임시 신청·의뢰를 생성하는 검사에서 실제 사용자 알림이 발송되지 않게 하는 운영 원칙
---

DB 기반 자동검사는 임시 신청·의뢰를 만들고 정리할 수 있으므로 실제 이메일과 SMS를 최하위 발송 함수에서 명시적으로 차단한다. 개별 테스트의 mock만 신뢰하지 않는다.

**Why:** 임시 의뢰가 정리된 뒤에도 외부 알림만 실제 사용자에게 남으면, 이메일에는 배정됐다고 나오지만 관리자와 중개사 화면에는 의뢰가 없는 상태 불일치가 생긴다.

**How to apply:** 외부 알림을 발생시킬 수 있는 검사 프로세스는 차단 환경값을 앱 import 전에 설정한다. 이메일·SMS 발송 함수는 그 값을 가장 먼저 확인하며, 내용 검사는 네트워크 대신 mock으로 수행한다.
