---
name: 주간 이메일 동의 마이그레이션
description: 주간 이메일 기본값 전환 시 기존 수신거부를 안전하게 보존하는 정책
---

일반회원과 승인 파트너의 주간메일은 기본 발송하는 옵트아웃 정책이다. 새 계정은 기본 TRUE다. 파트너 기존 FALSE 중 `weekly_email_updated_at IS NULL`인 값은 설정을 바꾼 적 없는 과거 기본값이므로 TRUE로 전환하고, 변경 시각이 있는 FALSE는 명시적 수신거부로 보존한다. 일반회원의 기존 FALSE도 다시 활성화하지 않는다.

**Why:** 사용자가 광고 없는 주간 정보는 가입·파트너 등록 계정에 기본 발송하고 이메일과 대시보드에서 언제든 수신거부하는 정책을 확정했다. 동시에 실제 수신거부를 마이그레이션이 되돌리면 안 된다.

**How to apply:** 기본값·대상 조회·스키마 마이그레이션을 바꿀 때 신규는 TRUE로 두되, 파트너는 변경 시각이 없는 과거 기본 FALSE만 활성화한다. 수신거부 링크와 계정별 설정 경로를 항상 유지한다.
