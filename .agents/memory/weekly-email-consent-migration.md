---
name: 주간 이메일 동의 마이그레이션
description: 주간 이메일 기본값 전환 시 기존 수신거부를 안전하게 보존하는 정책
---

일반회원과 승인 파트너의 주간메일은 기본 발송하는 옵트아웃 정책이다. 새 계정은 기본 TRUE다. TRUE 여부가 아니라 `FALSE + 변경 시각 있음`을 명시적 수신거부로 판정해 제외한다. 변경 시각 없는 과거 FALSE·미설정 값은 일반회원과 파트너 모두 발송 대상이다.

**Why:** 사용자가 약관에 따라 모든 회원·승인 파트너에게 기본 발송하고, 원하지 않는 사람만 주간 이메일 수신거부 기능으로 제외하는 정책을 확정했다. 실제 수신거부는 되돌리면 안 된다.

**How to apply:** 대상 조회와 발송 직전 재확인에서 `enabled IS FALSE AND updated_at IS NOT NULL`인 계정만 제외한다. 수신거부 링크와 계정별 설정 경로를 항상 유지한다.
