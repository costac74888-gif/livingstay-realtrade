---
name: 주간 이메일 동의 마이그레이션
description: 주간 이메일 기본값 전환 시 기존 수신거부를 안전하게 보존하는 정책
---

기존 `weekly_email_enabled = FALSE` 값은 과거 기본 미동의인지 사용자의 명시적 수신거부인지 구분할 수 없다. 따라서 마이그레이션은 이 값을 자동으로 TRUE로 바꾸지 않고 명시적 off로 보존한다. 새 계정은 기본 TRUE이며, 사용자가 아직 선택을 남기지 않은 경우에만 관심·알림·의뢰 행동으로 자동 opt-in한다.

**Why:** 수신거부는 복구 불가능한 개인정보 선호이며, 과거 데이터에 선택 시각이 없다면 적극적 마케팅 동의보다 보수적 보존이 안전하다.

**How to apply:** 수신 동의 기본값이나 마이그레이션을 바꿀 때 기존 FALSE를 일괄 true로 덮어쓰지 않는다. 이미 잘못 적용된 배포가 있었다면 백업 또는 감사 기록으로만 대상별 복구를 검토한다.
