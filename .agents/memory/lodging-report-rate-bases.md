---
name: 숙박 통계 신고율 기준
description: 관리자·데이터랩 전국 유형표와 시도별 비교 화면이 쓰는 서로 다른 신고율 분모 규칙
---

전국 숙박업 유형표에서 생활·관광·복합은 `영업신고호실 ÷ 건물 호실수`를 쓴다. 일반숙박은 건축물 호실수와 실제 영업 객실수의 모집단이 달라 `영업신고업체 ÷ 건물수`를 쓴다. 일반숙박은 세부 업태별로도 같은 업체·건물 기준을 보여 준다.

**Why:** 일반숙박은 보통 한 건물에 한 영업신고가 대응하므로, 객실수로 나누면 생활·관광 계열과 비교 가능한 신고율이 되지 않는다.

**How to apply:** 전국 유형별 표의 전체값은 각 유형의 해당 분자·분모를 합산한 값으로 계산한다. 지역별 신고율 비교 화면은 기존 연속성 때문에 일반숙박을 제외한 신고호실·호실수 기준을 유지한다. 두 화면의 전국 퍼센트가 달라도 서로 섞어 쓰지 않는다.
