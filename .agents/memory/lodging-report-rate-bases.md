name: 숙박 통계 신고율 기준
description: 관리자·데이터랩 전국 유형표에서 숙박 유형별로 다른 신고율 분모를 선택하는 규칙
---

전국 숙박업 유형표에서 생활만 `정상영업 신고객실수 ÷ 건축물대장 호실수`를 쓴다. 생활 행과 시도별 생활 영업신고표는 완료된 `생활+생숙` 건물, 활성 생활 신고, 원본 간 중복 제거, 건물별 객실 캡을 모두 같은 기준으로 사용한다. 관광·에어비앤비·농어촌민박·캠핑·한옥·복합은 `같은 유형의 활성 신고가 하나 이상 매칭된 건물수 ÷ 유형 건물수`, 일반은 `정상영업 신고업체 ÷ 일반 건물수`를 쓴다.

**Why:** 일반·관광은 호실수와 객실수 모집단이 다르다. 에어비앤비·농어촌민박·한옥은 신고 원본으로 만든 건물의 units에 신고객실수가 들어가 자기 자신과 비교될 수 있고, 캠핑은 객실 대신 사이트 수를 별도 저장하며, 복합은 hoCnt 보유율이 낮아 객실수 비율이 왜곡된다. 생활 전국표와 지역표가 모집단·업태·캐시 세대를 따로 쓰면 같은 지표가 서로 다른 숫자로 노출된다.

**How to apply:** 전국 유형별 전체값은 각 유형의 해당 분자·분모를 합산한다. 객실수 대비 전국·지역 보조지표에는 생활만 포함하며, 준공 전 건물은 대표 건물 선정 전부터 제외한다. 생활 전국표와 지역표의 캐시는 한쪽만 새 값으로 교체하지 않는다. 생활 외 유형의 대장 호실수는 참고값이며 신고객실수를 자르거나 나누지 않는다. 원장에 복합 업태는 없으므로 복합 건물은 연결된 활성 법정 신고 자체를 커버리지로 인정한다.
