---
name: 회원 접속이력
description: 일반회원 인증 세션의 감사 이력과 관리자 조회 경계
---

일반회원이 세션을 얻는 모든 경로(신규가입, 이메일 로그인, 기존·신규 카카오 로그인)는 접속이력을 같은 트랜잭션에 기록한다. IP 원문은 저장하지 않고 앱의 비밀 salt를 더한 해시만 보관한다.

**Why:** 로그인 방식이나 신규 계정 여부에 따라 이력이 누락되면 관리자 화면의 마지막 접속과 실제 이력이 서로 달라진다. 원본 IP 저장은 이 기능에 불필요한 개인정보 수집이다.

**How to apply:** 일반회원 인증 경로를 추가하거나 바꿀 때 접속이력 기록을 함께 추가한다. 조회는 관리자 전용으로 제한하고, 응답에는 로그인 시각·UA만 포함하며 최근 10건으로 제한한다.
