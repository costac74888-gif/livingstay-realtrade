---
name: 모바일 가독성 범위
description: 온비드 참고 글자 확대 요청의 적용 범위와 디자인 보존 요구
---

모바일 가독성 개선은 특정 공매 탭만이 아니라 부동산정보·운영정보·공매정보·공매목록을 포함한 앱 전반에 적용한다. 온비드 화면처럼 크고 명료하게 읽히게 하되 기존 디자인이 틀어지면 안 된다.

**Why:** 사용자가 작은 글씨를 읽을 수 없다고 명시했고, 전체 모바일 페이지 적용과 기존 디자인 보존을 함께 요구했다.

**How to apply:** 새 모바일 화면과 수정 화면에서도 본문·항목명·금액의 읽기 쉬운 크기를 유지한다. 실제 긴 주소와 큰 금액으로 줄바꿈·탭·표·버튼을 확인하며, 모바일 개선이 데스크톱과 인쇄를 바꾸지 않도록 구분한다.
