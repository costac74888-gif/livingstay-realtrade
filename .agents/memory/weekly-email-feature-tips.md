---
name: 주간 이메일 기능 소개 운영
description: ISO 주차 기반 8회차 이메일 기능 소개 콘텐츠의 범위와 시드 보존 원칙
---

기능 소개 콘텐츠는 ISO 주차를 1~8회차로 순환하는 고정 시리즈로 운영한다. 회차 범위를 벗어난 콘텐츠를 허용하면 저장은 되지만 어떤 주에도 발송되지 않는 조용한 운영 실패가 생긴다.

**Why:** 주간 이메일은 매주 자동 선택되므로, 관리자 UI와 DB가 같은 1~8 범위를 강제해야 실제로 전송되는 콘텐츠만 관리할 수 있다. 초기 콘텐츠는 첫 설정을 돕는 기본값일 뿐이다.

**How to apply:** 회차 추가·수정, DB 제약, 자동 선택 로직을 함께 바꾼다. 시드를 다시 실행할 때는 관리자가 수정한 콘텐츠를 보존하고, 새 기본 항목만 추가한다.
