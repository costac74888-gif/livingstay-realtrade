---
name: 캠핑 시설·사이트 집계
description: 캠핑의 건물형·대지형 시설수와 사이트 4분류를 공개 통계 및 종합매뉴얼에 적용하는 기준
---

공개 캠핑시설 수는 단순 건축물대장 건물수가 아니라 정상영업 중인 고유 건물형 시설과 건물 없는 대지형 영업신고시설을 합하고 동일 장소·사업장 중복을 제거한다. 휴업·폐업 등 비활성 원장은 보존하되 공개 시설수와 사이트수에서 제외한다.

**Why:** 야영장은 건물 없이 대지만 사용하는 시설이 많아 건물만 세면 과소 집계된다. 반대로 건물수와 전체 신고수를 단순 합산하면 건물에 연결된 신고와 복수 원본을 이중 집계한다.

**How to apply:** 고유 시설 집계는 활성 건물 연결 시설 + 활성 미연결 대지형 시설 - 신뢰 가능한 중복으로 계산한다. 사이트 수는 일반야영, 자동차야영, 글램핑, 카라반 4종을 별도 보존하고, 카라반은 설치 카라반과 개인 카라반 사이트를 합친다. 시설 유형은 단일 4종 또는 복합으로 표시하며 사이트 수량 미입력도 공개상 복합에 넣되 내부에서는 실제 복합과 미확인을 구분한다. 세부 통계의 신고업체는 마스터 건물과 연결된 중복 제거 시설 수, 신고사이트는 그 시설의 사이트 합계, 신고율은 매칭 시설 수÷전체 활성 시설 수로 통일한다. 신고번호 개수나 캠핑 건물 커버리지를 같은 행에 섞지 않는다. 고캠핑 API 제공 범위는 전체 시설수가 아니라 세부 사이트 정보의 커버리지로 취급한다. 향후 종합매뉴얼에 이 기준을 반영한다.
