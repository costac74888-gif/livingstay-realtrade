name: 매물의뢰 철회 상태
description: 매물의뢰 철회 시 기록 보존과 이후 처리 제한 원칙
---

매물의뢰 철회는 영구삭제가 아니라 `철회됨` 최종 상태로 저장하고, 원본 의뢰·담당 중개사 배정·채팅·변경 이력을 보존한다. 철회 전에는 담당 중개사가 신규·처리중·완료 상태를 양방향으로 수정할 수 있다.

**Why:** 접수 알림 문자만 발송된 뒤 원본과 이력까지 삭제되면 관리자와 담당 중개사가 의뢰가 사라진 이유를 확인하거나 복구할 수 없다.

**How to apply:** 일반회원의 철회 기능에는 상태 전환만 사용한다. 철회 전 상태 수정은 처리중 진입·이탈 때 담당 단지 매물현황 수량도 함께 증감한다. 철회된 의뢰는 관리자·등록자·배정 중개사의 기록 화면에 남기되 공개 목록에서는 제외하고, 담당 중개사가 다시 처리중이나 완료로 되돌릴 수 없게 한다. 관리자용 테스트·오등록 영구삭제와 회원삭제는 실행 전에 원본·이력·채팅·사진·찜을 복구 보관소에 저장하고 실행 관리자·시각·경로를 남긴다. 보관 실패 시 실제 삭제도 중단한다.
