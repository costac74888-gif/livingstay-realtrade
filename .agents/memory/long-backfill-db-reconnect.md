---
name: 장시간 백필 DB 재접속
description: 장시간 API 백필에서 PostgreSQL 연결 단절을 안전하게 복구하는 원칙
---

장시간 API 백필은 commit 단위를 재처리 가능한 크기로 제한하고, DB 연결이 끊기면 현재 단위를 멱등하게 다시 실행한다. 재접속 횟수는 제한하며 지수형 backoff를 사용한다.

**Why:** 수 시간 동안 같은 PostgreSQL 연결을 유지하면 SSL 연결이 예고 없이 종료될 수 있다. commit 결과가 불명확한 순간에도 작업 단위가 멱등하면 데이터 중복 없이 재실행할 수 있다.

**How to apply:** 상태 lease를 사용하는 백필은 새 연결을 얻은 직후 run_id 소유권을 다시 확인한 뒤에만 쓰기를 재개한다. 교체 연결과 cursor 생성이 실패하면 이미 빌린 풀 연결도 반드시 반환한다.
