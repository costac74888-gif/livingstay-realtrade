---
name: 고캠핑 웹 전용 시설 보강
description: basedList API에 없고 공식 웹에만 있는 캠핑장의 사진·예약 링크를 안전하게 보강하는 원칙
---

고캠핑 웹 자료는 정부 캠핑 원장과 정규화된 시설명+주소가 양쪽 모두 정확히 1건일 때만 자동 연결한다. 주소만 같거나 어느 한쪽에 중복 후보가 있으면 자동 반영하지 않는다.

**Why:** 고캠핑 웹에는 basedList 공개 API에서 빠진 시설이 상당수 있지만, 주소 단독 연결은 후속 사업자나 같은 주소의 다른 시설에 예약 링크·사진을 잘못 공개할 위험이 있다.

**How to apply:** 전체 목록의 화면 표시 총계와 실제 파싱 카드 수가 정확히 같은지 먼저 검증하고, 성공한 상세 조회는 데이터 유무와 무관하게 완료 표식을 남긴다. 쓰기 직전 원장 행을 다시 잠가 기존 값을 보존한다.
