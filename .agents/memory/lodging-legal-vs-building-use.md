---
name: 숙박 법정분류와 건축물 용도
description: 숙박 영업신고와 건축물대장 정보가 충돌하거나 중복될 때 적용할 분류 원칙
---

숙박의 주 분류는 법정 영업 유형으로 관리하고, 건축물대장 용도는 별도 값으로 보존한다. 현재 활성 신고는 상태명이 정확히 `영업/정상`인 경우만 인정한다. 과거 분류 출처는 문구만 보고 추정하지 않는다. 건축물대장 계보가 독립적으로 확인되고 원문 재판정이 저장 분류와 일치할 때만 대장 출처를 복원하며, 신고 출처는 현재 활성 신고의 합성 분류가 저장값과 일치할 때만 복원한다.

**Why:** 외국인관광 도시민박·농어촌민박 등은 주택에서 영업할 수 있어 영업 유형을 건축물 용도로 추정하면 오분류된다. 휴업·취소 등을 활성으로 세거나 영업신고로 건축물대장 확정값을 덮어써도 통계와 복구가 왜곡된다. 검증 시각과 그럴듯한 상세문구만으로는 대장 출처를 증명할 수 없으며, 출처 복원이 기존 보호 범위를 넓히면 이후 재분류가 부당하게 막힌다.

**How to apply:** 별도 법령 등록은 공중위생 신고보다 우선하되 서로 다른 별도 유형이 함께 있으면 복합으로 보류한다. 주소가 여러 건물에 맞으면 자동 연결하지 않고, 건축물대장 출처의 확정 분류는 명시적 검토 없이 소급 변경하지 않는다. 출처 복원과 신고 데이터 변경은 같은 트랜잭션 경계에서 직렬화하고, 복원된 출처 자체만으로 보호 대상을 새로 늘리지 않는다.
