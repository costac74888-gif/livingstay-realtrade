---
name: 숙박 법정분류와 건축물 용도
description: 숙박 영업신고와 건축물대장 정보가 충돌하거나 중복될 때 적용할 분류 원칙
---

숙박의 주 분류는 법정 영업 유형으로 관리하고, 건축물대장 용도는 별도 값으로 보존한다. 현재 활성 신고는 상태명이 정확히 `영업/정상`인 경우만 인정한다. 과거 분류 출처는 문구만 보고 추정하지 않는다. 건축물대장 계보가 독립적으로 확인되고 원문 재판정이 저장 분류와 일치할 때만 대장 출처를 복원하며, 신고 출처는 현재 활성 신고의 합성 분류가 저장값과 일치할 때만 복원한다. 지도 범례는 `관광숙박` 하나로 유지하고, 연간 공식 관광숙박업 원장의 세부업종은 그 하위 통계와 정확히 연결된 상세 뱃지로만 표시한다.

**Why:** 외국인관광 도시민박·농어촌민박·호스텔업 등은 영업등록 유형과 실제 건축물 용도가 다를 수 있어 영업 유형을 건축물 용도로 추정하면 오분류된다. 휴업·취소 등을 활성으로 세거나 영업신고로 건축물대장 확정값을 덮어써도 통계와 복구가 왜곡된다. 검증 시각과 그럴듯한 상세문구만으로는 대장 출처를 증명할 수 없으며, 출처 복원이 기존 보호 범위를 넓히면 이후 재분류가 부당하게 막힌다.

**How to apply:** 별도 법령 등록은 공중위생 신고보다 우선하되 서로 다른 별도 유형이 함께 있으면 복합으로 보류한다. 주소가 여러 건물에 맞으면 자동 연결하지 않고, 건축물대장 출처의 확정 분류는 명시적 검토 없이 소급 변경하지 않는다. 관광숙박 연간 원장은 영업중 등록사업장·객실 통계만 대체하고 건물 유형·건물 수·호실 수와 다른 숙박유형은 바꾸지 않는다. 출처 복원과 신고 데이터 변경은 같은 트랜잭션 경계에서 직렬화하고, 복원된 출처 자체만으로 보호 대상을 새로 늘리지 않는다.

연간 공식 원장의 전국 합계 적용과 개별 건물 연결은 분리한다. 업체명·주소가 정확히 일치한 행만 상세에 연결하고, 미연결·모호·충돌 행은 상세 연결에서 제외하되 공식 합계 적용은 막지 않는다.

**Why:** 공식 원장은 전국 집계의 기준이지만 건물 마스터와 명칭·주소 차이가 많아, 상세 연결 실패를 합계 적용 차단 조건으로 쓰면 유효한 원장 전체를 적용할 수 없다.

**How to apply:** 연결 상태는 미리보기 참고 정보로 표시하고, 승인된 영업중 행 전체는 관광숙박 신고업체·객실 통계에 사용한다. 전체 신고업체·객실 합계에는 기존 관광 값과 승인 원장 값의 차이를 반영하되 건물수·호실수·신고율은 바꾸지 않는다. 관광 세부통계는 법정 8개 업종을 고정 순서로 모두 표시하며 원장에 활성 행이 없는 업종도 0으로 표시한다. 상세 뱃지는 정확히 일치한 연결만 사용한다.
