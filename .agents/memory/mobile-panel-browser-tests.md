---
name: 모바일 패널 브라우저 테스트
description: 모바일 상세·지도 흐름을 실제 브라우저에서 안정적으로 재현할 때 지켜야 할 패널 상태 규칙
---

모바일 브라우저 테스트에서 검색 패널 토글을 무조건 클릭하지 말고, 현재 접힘 상태를 먼저 확인한 뒤 필요할 때만 연다.

**Why:** 건물 상세를 여는 경로에 따라 검색 패널의 기존 열린 상태가 유지된다. 연속 흐름에서 토글을 무조건 누르면 패널을 열려던 단계가 오히려 닫아 칩이 보이지 않는 간헐적 실패가 생긴다.

**How to apply:** 관심단지·최근조회처럼 접힌 검색 패널 안의 요소를 누르는 브라우저 테스트는 `collapsed` 상태를 확인하는 상태 기반 헬퍼를 사용한다.
