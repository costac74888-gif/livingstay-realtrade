---
name: URL 인코딩 인증값 마스킹
description: 외부 API 예외를 로그나 상태 DB에 저장하기 전에 인증값 표현을 제거하는 규칙
---

외부 API 예외 문자열은 원문 환경변수 치환만으로 마스킹하지 않는다. 원문, URL 디코딩 값, 단일·이중 URL 인코딩 값과 알려진 인증 쿼리 파라미터를 모두 제거한다.

**Why:** HTTP 클라이언트 예외는 실제 요청 URL을 URL 인코딩된 형태로 포함할 수 있어, 원문 키만 치환하면 상태 DB와 로그에 인증값이 남는다.

**How to apply:** 외부 요청 예외를 `app_meta`, 작업 로그, 관리자 응답에 기록하는 모든 수집기와 러너에서 공통 마스킹 함수를 거친다. 회귀 테스트는 원문·인코딩·이중 인코딩을 포함한다.

새 실행이 과거 상태 문서를 인수할 때는 이전 `last_error`를 초기화하고, 성공 또는 정상적인 빈 응답 뒤에도 오류를 지운다. 그렇지 않으면 이미 해결된 오류와 과거 인증 URL이 관리자 화면에 계속 남는다.
