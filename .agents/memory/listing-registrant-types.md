---
name: 매물 등록자유형 호환
description: 등록자유형 3분류 개편 시 기존 agent/other 매물의 데이터 보존 원칙
---

새 매물등록 UI에는 owner, building_owner, business 세 유형만 노출한다. 기존 매물의 agent/other 값은 백엔드에서 계속 허용하고, 수정 모달에서는 숨김 옵션으로 유지해 사용자가 저장하지 않아도 값이 owner로 조용히 바뀌지 않게 한다.

**Why:** 과거 매물의 등록자유형을 표시하지 않거나 owner로 대체하면, 기존 회원이 단순히 매물 수정 화면을 열고 저장하는 과정에서 데이터가 의미 없이 변경된다.

**How to apply:** 등록자유형 옵션을 추가·개편할 때 신규 등록 화면의 노출 목록과 기존 데이터의 읽기·수정 보존을 별도로 검증한다.
