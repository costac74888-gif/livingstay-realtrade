name: 분석 보고서 인쇄 그리드 잘림
description: 고정 A4 인쇄 영역에서 브라우저의 내용 최소 높이와 퍼센트 높이가 겹칠 때 검증 원칙
---

고정 크기 A4 그리드 안의 자식은 `height:100%`만으로 클리핑이 해결되지 않는다. 인쇄 브라우저가 콘텐츠 최소 높이나 상위 트랙을 기준으로 퍼센트를 계산해, 눈에 보이는 영역보다 큰 박스를 만들 수 있다. 위치를 눈으로만 보지 말고 자식과 실제 클리핑 영역의 하단 좌표를 비교한다.

**Why:** PDF는 여전히 A4 한 페이지였지만 헤드라인 문구와 하단 탭이 그리드 밖에서 잘렸다. 문구 크기만 줄이거나 퍼센트 높이를 주어도 클리핑은 남았다.

**How to apply:** 원래 배치가 고정된 인쇄 보고서를 손볼 때, 차트 아래의 반복 산식은 의미를 보존해 인쇄용으로 축약하고, 헤드라인·주의사항·탭의 실제 경계가 부모 영역 안에 드는지 PDF 렌더링과 브라우저 좌표를 함께 확인한다.
