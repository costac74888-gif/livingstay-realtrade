name: 세 분석 보고서 화면 위계
description: 투자·임대·운영 분석 화면 간 종합평가와 보고서 작업의 일관성
---

부동산투자분석·임대수익분석·숙박운영분석은 종합평가를 각 우측 결과 열 맨 위에, 상세·관심·인쇄·공유 작업을 결과 영역 하단의 같은 형태에 둔다. 근거와 유의사항은 화면 아래의 접이식 산출근거에서 확인하도록 한다. PC 투자분석 우측 카드의 중복 사진은 제거하되 작은 화면에서 필요한 사진 접근성은 보존한다.

**Why:** 사용자가 종합평가를 세 모드 모두 우측 상단 세로 열에 배치하도록 명시적으로 정정했다. 판정과 작업을 같은 위치에서 찾을 수 있고, 투자분석 우측 카드의 중복 사진·긴 근거를 줄여 균형을 맞춘다.

**How to apply:** 분석 화면의 결과 카드나 인쇄 연결을 변경할 때 세 모드의 판정·작업 위치와 근거 접근 경로를 함께 확인한다.
