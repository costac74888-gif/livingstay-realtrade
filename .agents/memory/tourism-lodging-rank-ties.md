---
name: 관광숙박 검색순위 공동순위
description: 검색TOP500 원본의 공동순위와 목록·지도 구간 검증 기준
---

관광숙박 검색TOP500 원본에는 공동순위가 있으므로 500행의 순위값이 모두 유일하거나 1부터 500까지 정확히 연속한다고 가정하지 않는다.

**Why:** 실제 최신 500행 원본에는 일부 공동순위가 있어 고유 순위값은 493개였지만, 화면 요구 구간은 목록 99행과 지도 401행으로 정확했다. 순위 유일성 검증은 정상 원본을 잘못 거부한다.

**How to apply:** 원본 승격과 API 검증에서는 전체 500행, 목록 구간 99행, 지도 구간 401행을 확인한다. 최신 원본 선택 뒤에도 반드시 `stat_type`을 다시 제한해 같은 파일명의 다른 관광 통계가 섞이지 않게 한다.
