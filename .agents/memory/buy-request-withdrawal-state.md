---
name: 매수의뢰 철회 상태
description: 매수의뢰의 철회 상태와 담당 중개사 상태 전이 규칙
---

매수자가 철회한 매수의뢰의 `철회됨` 상태는 최종 상태다. 본인 철회 뒤 담당 중개사나 다른 흐름이 이를 `처리중` 또는 `완료`로 다시 바꾸면 안 된다.

**Why:** 철회는 연락·중개 진행을 중단한다는 사용자 의사 표시다. 상태 순서의 기본값으로 처리하면 알 수 없는 상태가 신규 상태처럼 취급되어 담당 중개사가 철회 건을 재활성화할 수 있다.

**How to apply:** 매수의뢰 상태를 변경하는 모든 서버 경로에서 철회 상태를 명시적으로 거부하고, 새 상태 전이나 배치 처리도 이 최종성을 유지한다.
