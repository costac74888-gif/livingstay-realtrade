---
name: 개발·운영 DB 식별
description: 개발 전용 데이터 작업에서 운영 DB를 정확히 차단하는 기준
---

개발 전용 staging이나 검증 DDL은 환경 플래그 또는 연결 URL 문자열만으로
개발·운영을 판별하지 않는다. 현재 연결과 별도로 연 운영 연결의
`current_database()`, 서버 주소, 서버 포트를 비교하고, 같거나 운영 연결을
확인할 수 없으면 쓰기와 DDL을 차단한다.

**Why:** Replit 개발 워크스페이스에서도 배포 관련 플래그가 production 값으로
보일 수 있고, URL 문자열이 같아 보여도 연결 풀의 실제 개발 DB 대상은 별도일 수
있어 두 방식 모두 잘못된 허용·차단을 만들었다.

**How to apply:** 개발 전용 staging 테이블 생성, 승인 배치, dry-run, 이후 운영
승격 경로를 추가할 때 같은 실제 DB 지문 게이트를 유지하고 실패 시 닫는다.
