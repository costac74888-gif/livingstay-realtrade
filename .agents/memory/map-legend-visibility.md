---
name: 지도 범례 공개 범위
description: 미분류 노출 예외와 공매 건물 집계를 숙박 원장·합계와 분리하는 이유
---

미분류 범례는 개발 프리뷰와 인증된 관리자의 명시적인 관리자 지도 모드에서만 노출한다. 관리자 로그인 쿠키가 있어도 운영 일반 지도 모드에서는 숨긴다. 범례를 숨기는 것은 원장 삭제나 전국 숙박시설 합계에서 제외하라는 뜻이 아니다. 외도민업은 범례의 축약 표시이며 정식 허가업종을 개명하지 않는다.

**Why:** 사용자가 운영앱에 미분류가 여전히 보인다고 재차 지적했다. 로그인된 관리자 신분과 현재 화면의 관리자 모드를 혼동하지 않아야 하며, 화면 정리가 정부 원장 분류나 기존 집계 기준을 바꾸지 않아야 한다.

**How to apply:** 범례 표시 정책과 데이터 필터를 분리한다. 기존 관리자 지도 옵션과 서버 관리자 세션이 모두 있을 때만 운영 관리자 예외를 허용한다. 일반 지도에서는 관리자 쿠키만으로 예외를 허용하지 않는다.

통계의 공매 행과 지도 범례의 대표 숫자는 전체 공개 공매 물건 수로 맞춘다. 연결 건물 수는 별도 지표로 유지하며 건물별 중복을 제거한다. 미연결 물건도 물건 수에는 포함하되 건물 수로 추정하지 않는다. 공매는 새로운 숙박 용도가 아니며 숙박 전체 합계에 더하지 않는다.

**Why:** 연결 건물 수만 같은 ‘공매’ 이름으로 표시해 목록의 물건 수와 다른 숫자가 나왔다. 사용자가 목록과 동일한 물건 수를 대표 숫자로 선택했고 연결 건물 수는 별도로 표시하기로 확정했다.

**How to apply:** 전체 공개 목록과 같은 대상·회차 선택 규칙으로 물건 수를 계산하고 ‘건’ 단위를 명시한다. 통계 참고 행의 대표 값과 범례는 물건 수를 표시하고 연결 건물은 별도 열·설명에서 ‘개’로 구분한다. 숙박 총계와 공적 용도를 바꾸지 않으며 지역·상태 필터를 적용한 부분 목록 건수와 전국 총계를 혼동하지 않는다.
