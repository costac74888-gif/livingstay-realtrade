---
name: 지도 범례 공개 범위
description: 미분류 노출 예외와 공매 건물 집계를 숙박 원장·합계와 분리하는 이유
---

미분류 범례는 개발 프리뷰와 인증된 관리자의 명시적인 관리자 지도 모드에서만 노출한다. 관리자 로그인 쿠키가 있어도 운영 일반 지도 모드에서는 숨긴다. 범례를 숨기는 것은 원장 삭제나 전국 숙박시설 합계에서 제외하라는 뜻이 아니다. 외도민업은 범례의 축약 표시이며 정식 허가업종을 개명하지 않는다.

**Why:** 사용자가 운영앱에 미분류가 여전히 보인다고 재차 지적했다. 로그인된 관리자 신분과 현재 화면의 관리자 모드를 혼동하지 않아야 하며, 화면 정리가 정부 원장 분류나 기존 집계 기준을 바꾸지 않아야 한다.

**How to apply:** 범례 표시 정책과 데이터 필터를 분리한다. 기존 관리자 지도 옵션과 서버 관리자 세션이 모두 있을 때만 운영 관리자 예외를 허용한다. 일반 지도에서는 관리자 쿠키만으로 예외를 허용하지 않는다.

공매건물 통계는 현재 공개 공매에 연결된 확실한 건물마스터 수다. 건물 미연결 물건을 건물로 추정하거나 공매를 새로운 숙박 용도로 더하지 않는다.

**Why:** 사용자가 물건·회차 수가 아닌 건물 수를 요청했고, 여러 물건이 같은 건물에 속할 수 있으며 공매 건물은 기존 숙박 용도에 이미 포함된다.

**How to apply:** 숙박 총계를 보존하며 공매는 통계표의 별도 참고 행과 범례 숫자로 제공한다. 사용자가 열만 추가된 표에는 공매 항목이 안 보인다고 지적했으므로 열은 행을 대체하지 않는다. 미연결 물건까지 포함하는 공매 목록 건수와 같아야 한다고 가정하지 않는다.
