name: 프론트 배포 릴리스
description: 배포용 HTML·JS 생성과 원본 접근 차단을 안전하게 유지하는 릴리스 원칙
---

배포용 HTML과 압축 JS는 content-addressed 릴리스 디렉터리에 전부 먼저 생성한 뒤, 완성된 릴리스를 가리키는 마커만 원자적으로 교체한다. 원본 JS·HTML 차단은 환경 플래그와 유효한 릴리스 마커가 모두 있을 때만 켠다.

**Why:** 활성 서비스가 사용하는 산출물을 제자리에서 삭제·재생성하면 빌드 도중 원본이 잠시 공개되거나 기존 페이지의 압축 자산이 404가 될 수 있다. 빌드 실패 때도 직전 릴리스가 계속 동작해야 한다.

**How to apply:** 새 정적 HTML도 같은 릴리스 빌드에 자동 포함하고 실행 가능한 인라인 JS를 추출한다. 개발 서버는 원본을 유지하되, 배포 시작과 배포 검증은 반드시 릴리스 빌드를 먼저 완료한다.
