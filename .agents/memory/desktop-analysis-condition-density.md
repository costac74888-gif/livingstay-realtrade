---
name: 데스크톱 분석 조건 밀도
description: 임대 조건을 다열로 압축할 때 화면 균형과 슬라이더 넘침을 함께 검사하는 원칙
---

데스크톱의 조건 슬라이더는 카드 높이만 줄이지 말고 결과 열과의 하단 정렬, 슬라이더 내부의 가로 넘침, 조작 영역 크기를 함께 확인한다.

**Why:** 임대 조건을 세 열로 재배치해 좌우 하단을 맞추자, 비교적 좁은 데스크톱에서 기존 슬라이더 행의 최소 그리드 폭이 카드 밖으로 넘쳤다. 세로 높이 검사만으로는 이를 알 수 없었다.

**How to apply:** 조건 패널의 열 수나 패딩을 바꿀 때는 좁은 데스크톱과 넓은 데스크톱을 모두 렌더링한다. 행의 실제 scrollWidth와 clientWidth를 비교하고, 모바일 단일 열과 버튼 터치 영역은 보존한다.
