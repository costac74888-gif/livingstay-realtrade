---
name: 숙박 운영자 승인 단위
description: 숙박 운영자 신청의 신고번호 정규화와 중복 승인 방지 원칙
---

숙박 운영자 파트너는 숙박 신고 원장 한 건당 승인된 대표자 한 명만 허용한다. 사용자가 입력한 신고번호의 공백·하이픈·접두사 차이로 중복 승인이 우회되지 않도록, 원장과 매칭된 신청은 정규 원장 식별자를 기준으로 고유성을 강제한다. 신청자의 휴대폰 문자 인증은 필수지만, 신고번호가 선택 건물과 일치해도 자동승인하지 않고 관리자 빠른검토 대상으로만 분류한다. 최종 승인은 항상 관리자가 수행한다.

**Why:** 같은 신고시설을 가리키는 서로 다른 표기값으로 복수 계정과 공개 운영자 카드가 생성되면 대표자 권한과 공개 정보의 신뢰성이 깨진다. 공개적으로 알 수 있는 신고번호와 휴대폰 소유 확인만으로 시설 관리 권한을 주면 제3자가 운영자 계정을 탈취할 수 있다.

**How to apply:** 숙박 운영자 신청·승인·이관 로직을 변경할 때는 계정 생성 전에 원장 식별자 중복을 확인하고, 동시 요청은 데이터베이스 고유 제약으로 최종 차단한다. 매칭된 신고번호는 원장의 정규값을 저장한다. 문자 인증과 신고번호 일치는 신청 신뢰도·검토 우선순위에만 사용하고 관리자 승인 경계를 우회하지 않는다.
