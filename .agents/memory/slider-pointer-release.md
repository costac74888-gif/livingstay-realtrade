---
name: 슬라이더 터치 해제와 호환 클릭
description: 길게 누르기 중단 경계와 detail=0 클릭을 키보드로 단정하면 안 되는 이유
---

길게 누르기의 해제·취소는 버튼 밖에서 발생해도 처리한다. 터치 후
호환 클릭은 pointerdown에서 이미 처리한 증가를 반복하지 않는다.
detail=0만으로 키보드 활성화라고 판단하지 않는다.

**Why:** 경계 검사에서 터치 호환 클릭이 추가 증가를 일으켰고,
버튼 밖 해제·취소는 버튼에만 등록한 타이머 종료 listener에 도달하지 않았다.
DOM 교체·화면 이탈도 같은 위험을 갖는다.

**How to apply:** 포인터 활성화와 키보드 입력을 구분하고, 활성 반복만
전역 해제·취소·blur·문서 숨김에서 정리한다. 실제 touchEnd와 touchCancel,
키보드·직접입력 보존을 함께 확인한다.

누름 반복 검사의 기준값은 브라우저 해제 이벤트 순간에 기록한다. 호스트에서
값을 읽고 해제 명령을 보내는 두 왕복 사이의 정상 반복을 해제 후 증가로
해석하지 않는다. 정확한 값 일치와 최소 반복 횟수 조건은 유지한다.

**Why:** 실제 터치 검사에서 70을 읽은 뒤 해제 명령이 도착하기 전에 71이
되었고, pointerup·touchend·호환 click은 모두 이미 71인 상태에서 발생했다.
이 경우 지연시간이나 반복 간격을 조정하면 원인이 숨겨진다.

**How to apply:** 해제 이벤트 capture listener에서 기준값을 수집하고,
해제 직후와 여러 반복 간격 뒤의 값을 대조한다. 호환 클릭·취소·화면 이탈
검사는 별도로 유지하며 검증된 브라우저 외 환경까지 통과했다고 표현하지 않는다.
