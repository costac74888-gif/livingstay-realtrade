---
name: 관광 데이터랩 열지도 격리
description: 한국관광 데이터랩 원본을 기존 서비스 통계와 분리해 사용하는 원칙
---

한국관광 데이터랩에서 내려받은 방문자·관광소비·고캠핑 자료는 지역 열지도와 원본 검증을 위한 참고 데이터로만 사용한다. 검증되지 않은 값으로 기존 숙박·캠핑 통계의 합계, 신고업체·사이트 수, 신고율을 대체하거나 보정하지 않는다.

**Why:** 고캠핑 약 10만 사이트처럼 공개 API 및 현재 운영 원장과 큰 차이가 나는 값은 정보공개청구 원자료를 받아 범위와 산식을 검증해야 한다.

**How to apply:** 관광 데이터는 별도 저장소·API로 격리하고, 통계 반영은 출처 범위와 중복 제거 기준이 별도로 확정된 뒤 명시적 승인을 받아 진행한다.

같은 `source_period`라도 재다운로드 파일이 공존할 수 있으므로, 관광 데이터 조회는 최신 적재 파일 1개를 먼저 고른 뒤 그 `source_file` 안에서만 집계한다. 검색순위의 순위값은 전국 순위이므로 지역별 TOP N 조회에 전국 TOP20 상한을 재사용하지 않는다.

**Why:** 기간만으로 묶으면 같은 기간의 구·신 파일이 섞여 수치가 비결정적이 되고, 전국 순위 상한을 지역 상세에 적용하면 정상 데이터가 있어도 인기 관광지가 빈 목록으로 보인다.

**How to apply:** 관광 통계별 최신 파일을 적재시각과 파일명으로 결정적으로 선택한다. 전국 레이어만 전국 순위 상한을 적용하고, 지역 상세는 해당 지역 행 전체를 순위순으로 제한한다.
