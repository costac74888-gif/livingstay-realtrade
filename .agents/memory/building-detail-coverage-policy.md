---
name: 건축정보 보강과 완성률
description: 건축정보 수집의 보존 원칙과 조회 완료를 안내하는 기준
---

누락 보강에서는 기존 상세 기록과 정상 저장값을 초기화하거나 덮어쓰지 않는다. 실제 0도 정상값일 수 있다. 최신 원장에 맞춘 값 교체는 누락 보강과 다른 작업이므로 갱신 범위를 별도로 확정한다.

**Why:** 사용자는 기존 상세 자료를 보존하는 조건으로 기본 백필을 상세 보강으로 확장하고 전체 수집하는 방식을 승인했다.

**How to apply:** 기본정보가 있는 건물도 상세 누락 보강 대상에 포함하되, 초기화·전량 덮어쓰기 방식으로 전환하지 않는다.

기본정보 일부를 보유한 비율, API별 조회 완료, 개별 상세 항목의 실제 확보는 서로 다른 지표다. 정상 응답에 원본이 없는 경우는 조회 실패와 구분하고, 조회 완료를 모든 항목의 완성률로 안내하지 않는다.

**Why:** 기본 백필이 진행됐거나 과거 조회 시각이 있어도 건축면적·높이·지역정보·점검정보가 모두 확보됐다는 뜻은 아니며, 이를 혼동하면 사용자가 데이터 충실도를 오판한다.

**How to apply:** 관리자 진행 현황과 공개 상세 화면에서 성공·정상 미제공·실패·미조회를 구분한다. 일부 보조 API가 실패해도 이미 성공한 정보는 보존한다.
