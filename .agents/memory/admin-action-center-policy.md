---
name: 관리자 액션센터 알림 정책
description: 관리자 신규·승인·장애 신호의 표시와 이메일 발송 원칙
---

관리자가 알아야 할 신규 등록, 승인 대기, 처리 지연, 장애는 통계 대시보드의 통합 액션센터를 업무 기준화면으로 사용한다. 중요하거나 담당이 비어 있는 건만 즉시 이메일로 보내고 일반 건은 일일 요약으로 묶는다.

**Why:** 모든 이벤트를 건별 이메일로 보내면 거래량 증가 시 중요한 신호가 묻히며, 메뉴별 확인에 의존하면 승인과 배정을 놓칠 수 있다.

**How to apply:** 관리자 이메일 수신자는 별도 계정 필드가 아니라 공개 회사소개에 표시된 문의 이메일을 단일 원천으로 사용한다. 즉시메일은 DB에 내구성 있게 적재한 뒤 발송하고, 액션센터는 원본 상태를 실시간 집계한다.
