---
name: 관심단지 건물 ID 검증
description: 마스터 데이터 교체 뒤 관심단지가 다른 건물 상세로 연결되는 것을 막는 원칙
---

관심단지에 저장된 `master_building_id`는 현재 마스터에 같은 숫자가 존재한다는 이유만으로 신뢰하지 않는다. 저장된 관심주소와 현재 건물 주소가 일치할 때만 사용하고, 불일치하면 주소와 건물명을 기준으로 현재 ID를 다시 찾는다.

**Why:** 개발·운영 마스터를 다시 적재하거나 병합하면 예전 숫자 ID가 현재는 다른 지역 건물을 가리킬 수 있다. 존재 검사만 하면 링크는 정상처럼 보여도 엉뚱한 상세페이지가 열린다.

**How to apply:** 관심단지 조회·저장·데이터 이전에서 건물 ID를 사용할 때 도로명 또는 지번주소로 함께 검증한다. 복구 가능한 레코드는 현재 ID로 교정하고, 주소 매칭도 안 되면 잘못된 ID로 이동시키지 않는다.
