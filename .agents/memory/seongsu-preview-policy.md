---
name: 성수동 직접 테스트 Preview
description: 목업 기반 가상 매물 체험 우선순위와 운영/개발 분리 원칙
---

실제 매물이 없어도 사용자가 당초 목업에 맞춘 개발 Preview에서 직접 비교·예약을 테스트할 수 있도록 성수동1가·2가의 가상 매물을 최소 12개 유지한다.
사진·가격·면적·인원·편의시설·날짜와 서로 다른 가상 위치를 채우고 숙박 일별, 비숙박 주·달력 월, 마감 날짜를 포함한다.
매매·영업권 양도·공매는 독립 레이어의 가상 항목으로만 제공한다.

**Why:** 사용자가 2026-10-11에 “매물이 없더라도 테스트매물을 여러 개 … 성수동 기준으로”를 추가하며, 목업 Preview의 직접 체험을 최우선으로 명시했다.

**How to apply:** 이후 목업·통합 단계에서도 빈 목록으로 돌아가지 않게 한다. 테스트용/가상 공간 이미지/실재 및 법적 운영 확인 아님을 명확히 표시하고 실제 연락처·소유자·사건·영업신고를 가져오지 않는다. 운영 데이터·숙박 통계·실제 결제·발송·정산과 혼합하지 않는다. PC·모바일 주소와 체험 순서·계정 제공 방식·미완료 범위를 함께 보고한다.

가상 데이터 표시·사진·정확한 가상 좌표·모의 결제 버튼은 소유한 격리 Preview가 서버에서 부여한 권한으로만 활성화한다. 일반 공유 HTML에 데모 활성 플래그를 고정하지 않는다.

**Why:** 공유 템플릿은 일반/비공개 화면과 모바일 shell에도 재사용된다. 화면 스타일만으로 가상 데이터 공개나 결제 성공의 근거를 만들면 안 된다.

**How to apply:** 일반 화면은 기존 사진·위치 비공개 계약을 유지하고 서버의 격리 확인 없이 데모 기능을 활성화하지 않는다. 모의 결제는 사용자 동의 후 서명된 owned provider 이벤트를 원장에 반영하고, 토스 키 보유와 실제 토스 테스트 API 연결을 구분한다. 재시작 시 초기화·체험자 간 공유된 가상 계정이라는 한계도 안내한다.
