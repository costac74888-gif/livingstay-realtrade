---
name: 실시간 계산 중 직접입력 보존
description: 슬라이더 값 직접입력과 동기화가 동시에 일어날 때의 UX 제약
---

슬라이더 옆 숫자를 직접 입력하는 중에는 계산·기준값 갱신이 입력 요소를 교체하지 않아야 한다. 값 확정 또는 취소 뒤에만 표시 버튼을 갱신한다.

**Why:** 면적 자동 적용과 시장 기준가 갱신이 겹칠 때 재계산이 편집 중인 숫자 입력창을 제거해 실제 사용자 입력과 브라우저 검사가 모두 실패했다.

**How to apply:** 즉시 계산형 편집기에서 주변 값과 범위를 동기화할 때 현재 포커스를 가진 입력창을 보존하고, blur/확정 경계에서 버튼 표시로 전환한다.
