---
name: 비신뢰 문서 즉시 분석
description: 사용자 업로드 문서를 동기 웹 요청에서 안전하고 보수적으로 분석하는 원칙
---

사용자 업로드 PDF·엑셀·이미지를 즉시 분석할 때 네이티브 파서는 별도 프로세스 그룹에서 실행하고, 하드 타임아웃에는 OCR 자식까지 그룹 전체를 종료한다. 동기 웹 워커를 모두 점유하지 않도록 인스턴스당 분석 동시 실행은 하나로 제한한다.

**Why:** 파일 크기 제한만으로는 압축·렌더링 복잡도를 제한할 수 없고, 파서 부모만 종료하면 OCR 자식이 남을 수 있다.

**How to apply:** 비신뢰 문서를 동기 처리하는 모든 기능에 요청 크기, 픽셀·페이지, CPU·메모리, wall-clock, 프로세스 트리, 동시성 제한을 함께 적용한다.

운영 ADR은 같은 행에서 검증된 객실매출÷판매객실 합계를 기간별 ADR 단순평균보다 우선한다. 분리 파일은 같은 명시 기간의 매출 제공자 1개와 판매객실 제공자 1개일 때만 결합하고, 중복 제공자·총매출·기간 충돌은 섞지 않는다. 분모 없는 다기간 명시 ADR은 모든 값이 같지 않으면 비운다.

**Why:** 표를 평탄화하거나 기간이 다른 숫자를 합치면 그럴듯하지만 잘못된 운영지표가 즉시 공개된다.

**How to apply:** 열 제목과 행을 구조적으로 읽고, 지표의 의미·기간 계보·제공자 단일성이 호환되지 않으면 값을 비워 사용자가 직접 확인하게 한다.
