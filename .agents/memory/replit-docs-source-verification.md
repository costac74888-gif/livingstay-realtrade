---
name: Replit 문서 원문 확인
description: 문서 검색 요약과 공식 본문의 기능 지원 설명이 충돌할 때의 판단 원칙
---

Replit 기능 지원 여부가 중요할 때는 문서 검색의 생성 요약만으로 단정하지 말고 연결된 공식 문서 본문을 확인한다.

**Why:** 예약 배포의 Secrets 지원을 검색 요약이 미지원이라고 두 차례 설명했지만, 공식 Secrets 본문은 Static을 제외한 모든 배포 유형에서 지원한다고 명시했다. 요약과 원문이 충돌할 수 있다.

**How to apply:** 기능 미지원 판정이나 운영 매뉴얼의 사실 검토에서는 원문의 정확한 문장을 우선한다. 해당 프로젝트의 실제 게시 설정에 값이 반영되었는지는 기능 지원 여부와 따로 확인한다.
