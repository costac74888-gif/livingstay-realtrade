---
name: Chart.js 오버레이 배치 순서
description: Chart.js 캔버스 라벨과 DOM 배경·설명을 함께 배치할 때 지켜야 할 렌더링 순서와 테스트 동기화 원칙
---

Chart.js 위에 DOM 기반 사분면 배경·설명과 캔버스 기반 대표 라벨을 함께 표시할 때는 DOM 경계를 먼저 최종 좌표로 배치한 뒤, 그 실제 경계 상자를 점유 영역으로 삼아 라벨 위치를 찾아야 한다. 빈 공간이 없으면 겹치는 fallback을 강제로 그리지 않는다.

**Why:** 라벨을 먼저 계산하고 이후 플러그인 단계에서 사분면 경계를 옮기면, 계산 당시에는 안전했던 라벨이 최종 모바일 화면에서 설명과 겹친다. 고정 시간 대기는 애니메이션 길이 변경이나 느린 환경에서 불안정하다.

**How to apply:** DOM 오버레이 갱신은 데이터셋 그리기 전 단계에서 끝내고, 캔버스 라벨은 그 이후 실제 DOM 경계와 기존 라벨을 모두 피해 배치한다. 브라우저 테스트는 타임아웃 대신 Chart.js 애니메이션 완료 신호를 기다린다.
