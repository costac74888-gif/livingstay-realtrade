---
name: 자산분석 메뉴 공개 범위
description: 운영 앱의 자산분석 메뉴와 서명 공유 링크에 서로 다른 공개 범위를 적용하는 제품 정책
---

공용 상단 메뉴와 전체 메뉴의 “자산분석” 항목은 로그인 여부와 관계없이 항상 표시한다. 일반회원과 파트너는 로그인 후 세 분석을 이용할 수 있다. 유효한 서명 공유 링크의 비회원 직접 열람도 계속 허용한다.

**Why:** 사용자가 공용 메뉴 노출과 실제 분석 이용 권한을 분리하도록 명확히 요청했다. 이전 관리자 전용·메뉴 완전 제거 정책은 더 이상 유효하지 않다.

**How to apply:** 메뉴는 인증 상태와 무관하게 노출하고, 분석 화면·API에서 회원 또는 파트너 로그인 여부를 확인한다. 공유 토큰 접근은 이와 별도로 유지한다.
