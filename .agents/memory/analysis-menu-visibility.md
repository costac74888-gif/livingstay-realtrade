---
name: 자산분석 메뉴 공개 범위
description: 운영 앱의 자산분석 메뉴와 서명 공유 링크에 서로 다른 공개 범위를 적용하는 제품 정책
---

운영 앱의 공용 상단 메뉴와 전체 메뉴에서 자산분석은 운영관리자 세션만 단독으로 활성화된 경우에만 노출한다. 일반회원·사업자 세션이 함께 남아 있으면 공용 화면에서는 숨긴다. 다만 유효한 서명 공유 링크를 통한 비회원 직접 열람은 계속 허용한다.

**Why:** 같은 브라우저에서 관리자와 일반회원 로그인을 모두 사용하면 관리자 세션 쿠키가 남아 일반회원 햄버거에 관리자 메뉴가 노출될 수 있다. 제한적 공유 기능까지 중단하면 안 된다.

**How to apply:** 메뉴 노출 시 관리자 세션뿐 아니라 일반회원·사업자 세션 부재도 확인한다. 분석 페이지·공유 API 접근 권한은 별도로 판단하고 유효한 공유 토큰 접근은 관리자 전용으로 바꾸지 않는다.
