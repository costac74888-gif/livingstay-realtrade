---
name: 자산분석 메뉴 공개 범위
description: 운영 앱의 자산분석 메뉴와 서명 공유 링크에 서로 다른 공개 범위를 적용하는 제품 정책
---

운영 앱의 공용 상단 메뉴와 전체 메뉴에서 자산분석은 운영관리자 세션에만 노출한다. 다만 유효한 서명 공유 링크를 통한 비회원 직접 열람은 계속 허용한다.

**Why:** 자산분석 기능은 당분간 운영관리자만 메뉴에서 발견할 수 있어야 하지만, 이미 제공한 제한적 공유 기능까지 중단하면 안 된다.

**How to apply:** 메뉴 노출 권한과 분석 페이지·공유 API 접근 권한을 별도로 판단한다. 메뉴를 숨긴다는 이유로 유효한 공유 토큰 접근을 관리자 전용으로 바꾸지 않는다.
