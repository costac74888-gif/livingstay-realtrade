---
name: 자산분석 메뉴 공개 범위
description: 운영 앱의 자산분석 메뉴와 서명 공유 링크에 서로 다른 공개 범위를 적용하는 제품 정책
---

운영 앱의 공용 상단 메뉴와 전체 메뉴에서는 로그인 상태와 관계없이 자산분석 항목을 완전히 제거한다. 운영관리자는 전용 주소로 접근한다. 다만 유효한 서명 공유 링크를 통한 비회원 직접 열람은 계속 허용한다.

**Why:** 관리자 세션 쿠키가 공용 화면에 남는 경우 게스트나 일반회원 햄버거에 조건부 메뉴가 다시 나타날 수 있다. 공용 메뉴에서 완전히 제거해야 노출을 확실히 막을 수 있으며, 제한적 공유 기능까지 중단하면 안 된다.

**How to apply:** 공용 헤더와 전체 메뉴에는 자산분석 링크를 만들지 않는다. 분석 페이지·공유 API 접근 권한은 별도로 판단하고 유효한 공유 토큰 접근은 관리자 전용으로 바꾸지 않는다.
