---
name: 관리자 이벤트 알림 전달
description: 관리자 수신함 이벤트와 이메일 전달을 추가할 때 지켜야 할 원자성·응답 분리 원칙
---

신규 신청·회원 이벤트는 원본 쓰기와 같은 트랜잭션에서 수신자별 알림과 이메일 outbox를 적재하고, 이메일 네트워크 호출은 웹 요청 응답 경로에서 실행하지 않는다.

**Why:** 이메일 공급자 지연이나 장애가 회원가입·신청 응답을 늦추면 안 되며, 원본만 커밋되거나 알림만 남는 불일치와 중복 발송도 막아야 한다.

**How to apply:** 새 관리자 이벤트를 추가할 때 허용 이벤트·구독 UI·DB enqueue 매핑을 함께 확장하고, 안정적인 멱등 키를 유지한 백그라운드 outbox 워커로만 외부 발송한다.
