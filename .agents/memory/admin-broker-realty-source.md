---

관리자 건물마스터의 입점부동산 값은 주소 매칭된 브로커 표준데이터를 우선한다. 표준데이터 매칭이 전혀 없을 때만 기존 상권정보 캐시를 참고용 폴백으로 사용한다. 도로명 매칭 결과가 있으면 지번 매칭 결과를 합치지 않는다.

**Why:** 같은 열에서 화면·합계·엑셀이 서로 다른 출처의 수를 보이면 관리자가 데이터 신뢰성을 판단하기 어렵고, 도로명·지번 양쪽에 걸리는 동일 업소를 중복 집계할 위험이 있다.

**How to apply:** 입점부동산의 이름·건수·합계·내보내기 등 동일한 사용자 개념을 새로 추가하거나 변경할 때, 브로커 우선 및 도로명 우선 규칙을 함께 적용한다. Python 정규화가 필요한 계산값은 서버 정렬을 제공하지 않는다.
