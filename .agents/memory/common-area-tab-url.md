---
name: 공통 면적 입력과 탭별 URL
description: 한 면적 입력을 여러 분석 탭이 구독할 때 URL 갱신의 소유권
---

공통 전용면적 입력은 부동산투자·임대·운영에서 함께 쓰지만, 비활성 탭의 백그라운드 계산이 현재 탭의 URL 모드를 변경하면 안 된다.

**Why:** 부동산투자 탭에서 면적을 바꾸자 비활성 임대 탭의 입력 리스너가 실행되어 공유 가능한 투자분석 주소가 임대분석 주소로 바뀌었다. 새로고침하면 원래 보던 분석과 근거가 사라진다.

**How to apply:** 공통 입력의 계산 리스너는 실행 가능하더라도 URL, 공유 상태, 저장 등 외부에 보이는 부작용은 활성 탭을 확인한 후에만 수행한다. 탭 간 공유하는 시나리오가 늘어날 때도 같은 경계를 적용한다.
