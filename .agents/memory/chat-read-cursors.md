---
name: 채팅 읽음 경계
description: 조회와 읽음 처리 사이에 도착한 메시지가 읽음으로 사라지지 않게 하는 원칙.
---

읽음은 화면에 실제 전달된 마지막 메시지까지 제한한다. 읽음 처리 시점의
최신 메시지나 서버 현재 시각으로 확대하지 않는다. 과거 읽음 요청도
현재 읽음 위치를 되돌릴 수 없다.

**Why:** 조회 응답과 읽음 저장 사이에 상대방의 새 메시지가 도착하면
보지 못한 메시지가 읽음으로 사라질 수 있다.

**How to apply:** 채팅의 자동 읽음·수동 읽음·재접속 기능을 바꿀 때는
조회 이후 도착한 메시지가 계속 미읽음이고 재시도가 위치를 되돌리지 않는지 확인한다.
