---
name: 외부 API 백필 체크포인트
description: 재시작 가능한 외부 API 대량 작업의 소유권·호출 한도·진행 상태 보존 원칙
---

Autoscale 환경의 장시간 백필은 로컬 파일이나 프로세스 생존에 의존하지 않고, DB에 실행 소유권과 진행 지점을 저장한다. 상태 JSON이 TEXT 컬럼이면 읽을 때 명시적으로 역직렬화한다.

**Why:** 배포나 워커 종료 뒤 로컬 체크포인트가 사라지고, 날짜만 기록하는 실행 잠금은 중간 종료된 작업을 같은 날 재개하지 못한다. 오래된 프로세스와 새 프로세스가 동시에 상태를 쓰면 진행 지점도 후퇴할 수 있다.

**How to apply:** run_id가 일치할 때만 heartbeat·진행·종료 상태를 갱신하고, 일정 시간 이상 heartbeat가 끊긴 lease만 인계한다. 외부 API 일일 한도는 요청을 보내기 전에 DB에 예약·커밋하여 요청 직후 프로세스가 죽어도 호출량이 과소계상되지 않게 한다. 연결시간초과는 처리 완료로 넘기지 말고 같은 항목에서 장기 백오프한 뒤, 재접속 한도 소진 시 체크포인트를 열어 둔 실패로 종료한다. 재접속 대기 상태도 활성 lease로 취급해 감독기가 중복 작업을 띄우지 않게 한다.
