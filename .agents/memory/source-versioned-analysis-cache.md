---
name: 원장 기반 분석 캐시
description: 원장 갱신과 이동 기간 경계에서도 영속 분석 캐시가 오래된 값을 제공하지 않게 하는 원칙
---

영속 분석 캐시는 원장별 단조 증가 버전을 함께 저장하고, 조회 시 현재 버전과 일치할
때만 사용한다. 원장 변경 트랜잭션은 같은 트랜잭션 안에서 버전을 올린다.

**Why:** 삭제만으로 무효화하면 원장 갱신과 겹쳐 이전 스냅샷을 계산한 요청이 갱신
커밋 뒤 캐시를 늦게 저장하는 경합에서 오래된 값이 다시 살아날 수 있다.

**How to apply:** 원장 기반 집계를 새로 캐시할 때 관련 원장 버전을 모두 키 또는 캐시
메타데이터에 포함한다. `CURRENT_DATE` 같은 시간 의존 이동구간은 원장 변경 없이도
값이 달라지므로 애플리케이션 시간이 아닌 같은 DB 트랜잭션의 날짜 버킷도 포함한다.
