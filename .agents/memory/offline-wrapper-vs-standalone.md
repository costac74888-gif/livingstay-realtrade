---
name: 오프라인 실행기와 단독 CI 명령
description: 전체 검사의 주입 환경에서 통과해도 등록된 단독 명령에서는 실패할 수 있다는 검증 범위 원칙
---

전체 오프라인 실행기 통과만으로 등록된 단독 CI 명령의 통과를 추정하지 않는다. 두 진입 환경의 차이도 확인한다.

**Why:** 감싸는 실행기의 경로 주입 덕분에 전체 스모크가 통과했지만, 단독 스모크에서는 임시 작업공간의 중첩 빌드 검사가 프로젝트 모듈을 찾지 못한 일이 있었다. 제품 화면 회귀도 공급자 인증 오류도 아니었다.

**How to apply:** 실제 등록 명령을 그대로도 실행한다. 작업 디렉터리·자식 import 경로·안전 플래그의 상속 차이를 확인하고, 통과하도록 검사를 삭제하거나 감싸기 환경을 몰래 전제로 만들지 않는다.
