---
name: 병합 후처리 검사 격리
description: 앱 재시작 전 실행되는 후처리는 실행 중인 Preview나 실제 연결에 의존하지 않는다
---

병합 후처리의 브라우저 검사는 소유 임시 DB·HTTP 환경을 직접 준비한다.
실행 중인 Preview를 전제로 하지 않으며 검사 실패를 성공으로 바꾸지 않는다.

**Why:** 설정 스크립트가 workflow reconciliation보다 먼저 실행되므로,
앱이 중지된 상태에서는 5000 포트 접속이 거부된다. 기존 환경을 그대로
사용하면 실제 DB·공급자 키·알림으로 연결될 위험도 있다.

**How to apply:** 환경을 정리한 기존 소유 검사 실행기를 사용한다.
원래 assertion은 유지하고 상대 경로 캡처는 임시 작업공간에서 생성한다.
후처리 검증은 전체 회귀나 운영 Gate 승인으로 해석하지 않는다.
