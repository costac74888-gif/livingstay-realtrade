---
name: 숙박자산분석 공통 선택
description: 세 분석 모드가 공유하는 건물과 전용면적의 상태 경계 및 보고서 일치성
---

건물 선택과 전용면적은 부동산투자·임대수익·숙박운영의 공통 상태다. 탭 전환은 선택 건물의 사진을 다시 요청하거나 면적·입력 시나리오를 초기화하지 않는다. 임대의 조건 초기화는 공통 면적을 보존하지만 검색 영역의 전체 초기화는 건물과 면적을 함께 지운다. 부동산투자 실거래 추이의 면적 필터는 공통 면적이 바뀔 때 초기 선택을 맞추되, 추이 카드 안에서의 변경은 공통 면적을 덮어쓰지 않는다. 세 탭은 숙박운영 화면에서도 계속 노출한다.

**Why:** 이전 화면별 건물 카드와 면적 입력을 하나로 합치는 과정에서, 탭 진입 시 면적이 지워지거나 숙박운영 전용 스타일이 탭 바를 숨길 수 있다. 비동기 건물 교체 중에는 예전 건물 정보와 새 면적이 한 보고서에 섞일 위험도 있다.

**How to apply:** 분석 모드를 추가하거나 전환·초기화·공유 URL·최근 분석·보고서를 수정할 때 공통 선택 건물 ID를 기준으로 상태를 검증한다. 보고서는 현재 모드의 건물 자료가 공통 선택 ID와 일치할 때만 생성한다.
