---
name: 자산 전달과 전체 소스 지문
description: 보고서 전달의 자동 메타데이터 변경을 기능 소스 변경과 구분한다
---

자산 전달은 추적 중인 Library 메타데이터를 자동으로 바꿀 수 있어, 검사 후
전체 저장소 지문이 달라질 수 있다. 기능 코드가 바뀌었다고 단정하지 않는다.

**Why:** 검증·Git 저장 뒤 보고서를 전달하자 Library 메타데이터만 변경되어
전체 지문 비교가 실패했다. 검사 중의 기능 소스는 그대로였다.

**How to apply:** 가능하면 자산 전달을 최종 지문·Git 저장보다 먼저 한다.
이미 전달했다면 변경 파일을 확인하고 기능 코드와 메타데이터를 구분해
기록한다. 메타데이터만 바뀐 경우 전체 기능 검사를 반복하거나 파일을
되돌려 Library 등록을 지우지 않는다.
