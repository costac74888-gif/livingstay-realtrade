---
name: API 동기화 병렬 실행
description: 정기·수동 API 수집의 병렬화, 한도 배정, 상태 잠금 원칙
---

독립 API 수집은 동시에 실행하고, 같은 API 한도나 서비스키를 공유하는 단계만 같은 버킷으로 묶어 직렬 실행한다. 단계별 실행 상태는 별도 행에 저장해 한 단계의 지연·중단이 다른 단계 상태나 버튼을 덮어쓰지 않게 한다.

**Why:** 하나의 전역 잠금과 상태 문서가 장시간 실행 또는 외부 API 타임아웃 뒤 모든 수동 수집 버튼을 함께 막았다.

**How to apply:** 확인된 일일 기준 한도의 정확히 80%를 정기 동기화 목표로 사용하고 20%를 수동·실시간·복구에 보존한다. 공식 한도가 확인되지 않은 API는 임의 숫자를 만들지 말고 확인 필요로 표시한다. 실행 중 단계에는 모래시계와 현재/목표 숫자를 함께 보여준다.
