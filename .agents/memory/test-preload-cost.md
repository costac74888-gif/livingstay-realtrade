---
name: 검사 preload의 하위 CLI 비용
description: 브라우저 검사 계측이 프런트 빌더의 반복 CLI 실행까지 느리게 만들 수 있는 환경 제약
---

검사용 Node preload에서 무거운 브라우저 의존성을 무조건 불러오지 않는다. 실제 브라우저를 사용하는 검사에서만 계측을 설치한다.

**Why:** NODE_OPTIONS는 빌더가 반복 실행하는 minifier 프로세스에도 상속된다. 제품 빌드는 정상이어도 매번 브라우저 라이브러리를 초기화하는 비용이 쌓여 전체 검사에서 배포 파일 검사가 시간초과로 보일 수 있다.

**How to apply:** 검사 환경에서만 빌드가 느릴 때는 계측의 자식 프로세스 상속 비용을 먼저 비교한다. 제한시간을 늘리기 전에 빌더 자체 비용과 preload 비용을 구별한다.
