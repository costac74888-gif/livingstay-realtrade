---
name: 일반회원 팝업 로그인 화면 유지
description: 일반회원의 작업 중 로그인과 사업자 대시보드 이동을 구분하는 이유
---

일반회원의 공통 팝업 로그인은 현재 화면의 작업을 이어가게 한다.
사업자용 명시적 대시보드 이동은 별도로 유지한다.

**Why:** 통합 로그인 응답의 일반회원 기본 이동을 그대로 적용하자,
멤버십 신청 중 로그인한 사용자가 신청 화면을 떠나 마이페이지로 이동했다.

**How to apply:** 공유 로그인 팝업과 전용 로그인/역할 전환의 이동 정책을
구분한다. 신청·예약 등 중간 로그인 시나리오도 검증한다.
