---
name: 일반회원 팝업 로그인 화면 유지
description: 일반회원의 작업 중 로그인과 사업자 대시보드 이동을 구분하는 이유
---

일반회원의 공통 팝업 로그인은 현재 화면의 작업을 이어가게 한다.
사업자용 명시적 대시보드 이동은 별도로 유지한다.

**Why:** 통합 로그인 응답의 일반회원 기본 이동을 그대로 적용하자,
멤버십 신청 중 로그인한 사용자가 신청 화면을 떠나 마이페이지로 이동했다.

**How to apply:** 공유 로그인 팝업과 전용 로그인/역할 전환의 이동 정책을
구분한다. 신청·예약 등 중간 로그인 시나리오도 검증한다.

같은 계정·사업장·역할의 상태 재조회 알림은 계정 전환으로 취급하지 않는다.
처음 늦게 도착한 로그인 상태도 이미 진행 중인 확인창을 닫는 근거가 아니다.
로그아웃이나 실제 계정·사업장·역할 변경에는 확인창을 종료한다.

**Why:** 공유 헤더의 계정 상태 알림을 모두 전환으로 해석하면 중복 조회가
진행 중인 신청을 중단시킨다. 반대로 실제 전환을 무시하면 다른 계정의
화면에서 이전 신청을 계속할 위험이 있다.

**How to apply:** 이벤트 발생 횟수가 아닌 계정·역할·사업장 식별자 경계로
판정한다. 같은 상태 재조회, 늦은 최초 상태, 계정/역할 변경, 로그아웃을
분리해 검사한다.
