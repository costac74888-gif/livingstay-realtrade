---
name: 목업 디자인 기준
description: 사용자 제공 목업의 디자인 요구와 이후 제품 구조 변경을 함께 유지하는 원칙
---

사용자가 제공한 목업은 디자인 구현 기준이다. 단계별 기능 요구로 바뀌더라도
화면 구성·정보 위계·색상·글꼴·여백·카드·배지·로고 방향을 임의 스타일로 대체하지 않는다.
확인된 참고 자료와 최종 승인본은 구분하며, 미확인 글꼴·사진·최종본을 승인된 것으로
추정하지 않는다.

**Why:** 사용자가 “당초 목업대로 하라고 해”라고 반복 지시했다. 목업 요구가
기능 중심 단계 지시·검수에 연결되지 않아 별도 스타일이 구현됐으며,
사용자는 이를 명시적으로 수정하도록 요구했다.

**How to apply:** 후속 화면 작업은 실제 참고 이미지와 원문을 먼저 열고,
확정된 2.0 제품 구조와 충돌하는 부분만 최소 조정한다. 조정 이유·남은 차이를
문서에 기록하고 PC·모바일 실제 화면과 대조한다. 기능검사 PASS를 디자인 일치
근거로 대신하지 않으며, 사진 공개·정확 위치 보호와 실제 결제 승인 경계를 유지한다.
